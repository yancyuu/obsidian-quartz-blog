# 装饰器（Decorator）

> 装饰器是 Python 最实用的语法糖之一，**在不修改原函数的前提下增强其功能**（日志、计时、权限、缓存）。是 Python 进阶必考题。

## 一、本质：函数是一等对象 + 闭包

装饰器是一个**接收函数、返回新函数**的函数：

```python
def my_decorator(func):
    def wrapper(*args, **kwargs):
        print("before")
        result = func(*args, **kwargs)
        print("after")
        return result
    return wrapper

@my_decorator        # 语法糖，等价于 hello = my_decorator(hello)
def hello(name):
    print(f"hi {name}")
```

> 装饰器 = 高阶函数 + [闭包](闭包.md)。`@deco` 只是 `func = deco(func)` 的语法糖。

---

## 二、常用装饰器

| 装饰器                           | 作用                                                                     |
| -------------------------------- | ------------------------------------------------------------------------ |
| `@functools.wraps`               | **必备**：保留被装饰函数的元信息（`__name__`/`__doc__`）                 |
| `@property`                      | 把方法变成属性访问（见 [属性property的优缺点](属性property的优缺点.md)） |
| `@staticmethod` / `@classmethod` | 静态方法 / 类方法                                                        |
| `@functools.lru_cache`           | 自动缓存（备忘录）                                                       |
| `@dataclass`                     | 自动生成 `__init__`/`__repr__` 等                                        |

### 为什么要用 @wraps

```python
from functools import wraps
def deco(func):
    @wraps(func)            # 不加的话 hello.__name__ 会变成 'wrapper'
    def wrapper(*a, **k):
        return func(*a, **k)
    return wrapper
```

## 三、带参数的装饰器

需要**三层嵌套**（外层接收参数）：

```python
def repeat(times):                  # 第1层：接收参数
    def decorator(func):            # 第2层：接收函数
        @wraps(func)
        def wrapper(*args, **kwargs):
            for _ in range(times):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(3)        # @repeat(3) 返回真正的 decorator，再装饰 say
def say(): print("hi")
```

## 四、类装饰器

用 `__call__` 实现，可带状态：

```python
class Counter:
    def __init__(self, func):
        self.func = func
        self.count = 0
    def __call__(self, *args, **kwargs):
        self.count += 1
        return self.func(*args, **kwargs)

@Counter
def greet(): print("hi")
```

## 五、实战示例

**计时 + 日志装饰器**：

```python
import time, functools

def log_time(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"{func.__name__} 耗时 {time.time()-start:.3f}s")
        return result
    return wrapper

@log_time
def train(): ...
```

## 六、面试速答

> **Q：装饰器原理？**
> A：本质是高阶函数 + 闭包。`@deco` 等价于 `func = deco(func)`，用新函数包装原函数，在不改原代码的前提下增强功能。

> **Q：为什么要用 functools.wraps？**
> A：保留被装饰函数的 `__name__`/`__doc__` 等元信息，否则会被 wrapper 覆盖，影响调试和文档。

> **Q：带参数的装饰器怎么写？**
> A：三层嵌套：外层接收参数、中层接收函数、内层 wrapper 执行。
