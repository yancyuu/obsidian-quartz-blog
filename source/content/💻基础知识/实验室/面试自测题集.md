## 🐍 Python 部分

### 基础概念

**Q1. Python 的可变/不可变类型各有哪些？函数传参是值传递还是引用传递？**

- ⭐⭐ | [深拷贝与浅拷贝](../python/深拷贝与浅拷贝.md)
- 要点：不可变 = `int/float/str/tuple/frozenset`；可变 = `list/dict/set`。传参是**传对象引用**（对象不复制，但不可变对象"修改"会建新对象，表现像值传递）。

**Q2. `a=256; b=256`，`a is b` 是 True 还是 False？为什么？`a=257` 呢？**

- ⭐⭐⭐ | [==与is的区别](../python/==与is的区别.md)
- 要点：256 是 **True**（CPython 缓存 -5~256 小整数，a、b 指同一对象）；257 交互模式可能 **False**。结论：**比较值永远用 `==`，`is` 只判身份/None**。

### 原理

**Q3. GIL 是什么？为什么多线程不能加速 CPU 密集任务？最新的变化？**

- ⭐⭐⭐ | [GIL](../python/GIL.md)
- 要点：CPython 全局锁，任意时刻只一个线程执行字节码；根因是引用计数 GC 的原子性 + C 扩展线程安全。CPU 密集用多进程。**Python 3.13（PEP 703）引入实验性 No-GIL**，分阶段移除。

**Q4. Python 的 GC 机制？循环引用怎么处理？有 `__del__` 的循环引用能回收吗？**

- ⭐⭐⭐ | [python垃圾回收](../python/python垃圾回收.md)
- 要点：引用计数（主）+ 标记清除（解循环引用）+ 分代回收（提效）。**PEP 442（3.4+）后**循环引用里有 `__del__` 也能安全回收。3.12 增量 GC + 永生对象（PEP 683）。

**Q5. 闭包原理？写一个带参数的装饰器，为什么要用 @wraps？**

- ⭐⭐⭐ | [装饰器](../python/装饰器.md) · [闭包](../python/闭包.md)
- 要点：闭包 = 内层函数捕获外层自由变量。装饰器 = 高阶函数+闭包，`@deco` 等价 `f=deco(f)`。带参装饰器三层嵌套。`@wraps` 保留原函数 `__name__/__doc__`。

**Q6. 生成器和迭代器的区别？生成器的底层原理？**

- ⭐⭐ | [生成器](../python/生成器.md) · [迭代器](../python/迭代器.md)
- 要点：迭代器实现 `__iter__`/`__next__`；生成器是**用函数+yield 创建的迭代器**，暂停恢复靠保存栈帧状态。惰性求值、省内存。

**Q7. asyncio 怎么实现并发？协程里能跑 CPU 密集吗？怎么解决？**

- ⭐⭐⭐ | [异步如何实现的](../计算机原理/异步如何实现的.md)
- 要点：单线程 + 事件循环 + IO 多路复用（epoll）。协程 `await` 暂停交还控制权。**不能跑 CPU 密集**（阻塞事件循环），用 `run_in_executor` 丢线程/进程池。

### 代码题（看输出）

**Q8.** 说出输出：

```python
def add(item, lst=[]):
    lst.append(item)
    return lst
print(add(1)); print(add(2))
```

- ⭐⭐⭐ 高频 | 要点：`[[1], [1,2]]`。默认参数 `[]` 只创建一次被共享。改 `lst=None`。

**Q9.** 说出输出：

```python
funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])
```

- ⭐⭐⭐ | 要点：`[2,2,2]`。闭包延迟绑定，i 引用循环结束的值。改 `lambda i=i: i`。

## 🟢 Node.js 部分

### 基础

**Q1. Node 是单线程吗？为什么能高并发？不适合什么？**

- ⭐⭐⭐ | [Node基础与架构](../nodejs/Node基础与架构.md)
- 要点：JS 代码单线程，但 libuv 有**线程池**（磁盘/DNS/加密）。高并发靠非阻塞 IO + 事件循环。**不适合 CPU 密集**（阻塞事件循环）。

**Q2. CommonJS 和 ESM 的区别？**

- ⭐⭐ | [Node模块系统与Stream](../nodejs/Node模块系统与Stream.md)
- 要点：CJS 同步/运行时/`require`/不能 tree-shake；ESM 静态/编译时/`import`/支持 tree-shaking 和顶层 await。新项目用 ESM。

### 原理（事件循环是重点）

**Q3. Node 事件循环有几个阶段？`process.nextTick` 和 `Promise.then` 谁先执行？**

- ⭐⭐⭐ 必考 | [Node事件循环](../nodejs/Node事件循环.md)
- 要点：6 阶段（timers→pending→idle→**poll(IO)**→**check(setImmediate)**→close）。阶段间清空 microtask，**nextTick 优先级高于 Promise**。

**Q4. `setTimeout(fn,0)` 和 `setImmediate` 谁先？**

- ⭐⭐⭐ | 要点：主模块里**不确定**；但**在 IO 回调里 setImmediate 必先于 setTimeout**（poll 后直接进 check）。

**Q5. async/await 本质？下面代码有什么问题？**

```javascript
arr.forEach(async (item) => await save(item))
console.log("done")
```

- ⭐⭐⭐ | [Node异步编程](../nodejs/Node异步编程.md)
- 要点：async/await 是 Promise 语法糖。**forEach 不等 async 回调**，会立即打印 done。改 `for...of`（串行）或 `await Promise.all(arr.map(save))`（并发）。

**Q6. Stream 是什么？为什么用？pipe 的背压是什么？**

- ⭐⭐ | [Node模块系统与Stream](../nodejs/Node模块系统与Stream.md)
- 要点：分块处理数据，不一次性载入内存（处理 GB 文件不爆内存）。背压 = 消费慢时自动暂停生产，防内存堆积。推荐 `pipeline`。

**Q7. Node 单线程怎么用多核？Cluster 和 worker_threads 区别？**

- ⭐⭐⭐ | [Node多进程与内存管理](../nodejs/Node多进程与内存管理.md)
- 要点：Cluster = 多**进程**（独立内存，Web 服务扩多核）；worker_threads = 多**线程**（共享内存，CPU 密集）。生产用 PM2。

**Q8. V8 的 GC？Node 默认内存上限？**

- ⭐⭐ | [Node多进程与内存管理](../nodejs/Node多进程与内存管理.md)
- 要点：分代——新生代 Scavenge（复制）、老生代标记清除+标记整理。默认老生代约 1.4GB，用 `--max-old-space-size` 调。

### 代码题（事件循环执行顺序）

**Q9.** 说出输出顺序：

```javascript
console.log("1")
setTimeout(() => console.log("2"))
setImmediate(() => console.log("3"))
Promise.resolve().then(() => console.log("4"))
process.nextTick(() => console.log("5"))
console.log("6")
```

- ⭐⭐⭐ 经典 | 要点：`1 6 5 4` 然后 `2/3`（2 和 3 顺序不定）。同步→nextTick→Promise→宏任务。

## 🔁 跨语言对比（高级题）

**Q1. Python 的 GIL 和 Node 的单线程，高并发机制有什么异同？**

- ⭐⭐⭐ | [GIL](../python/GIL.md) · [Node基础与架构](../nodejs/Node基础与架构.md)
- 要点：都是单线程执行用户代码 + 事件循环/IO 多路复用做高并发 IO。**区别**：Python 有 GIL 但支持真线程（IO 时释放 GIL）；Node 主线程无真线程（靠 libuv 线程池）。CPU 密集：Python 多进程，Node 用 worker_threads。

**Q2. Python asyncio 和 Node 事件循环，谁更原生？**

- ⭐⭐ | [异步如何实现的](../计算机原理/异步如何实现的.md) · [Node事件循环](../nodejs/Node事件循环.md)
- 要点：Node 异步是**基因级原生**（整个生态 async）；Python asyncio 是**后加的库**，需 `async/await` 显式声明且会"传染"。Node 写异步更自然。

**Q3. Python GC 和 V8 GC 对比？**

- ⭐⭐ | [python垃圾回收](../python/python垃圾回收.md) · [Node多进程与内存管理](../nodejs/Node多进程与内存管理.md)
- 要点：都用分代 + 标记清除思想。Python 以**引用计数为主**（需 GIL 保护）+ 分代标记清除补循环引用；V8 新生代用 **Scavenge 复制算法**、老生代标记清除+整理，不用引用计数。

**Q4. 两者如何处理 CPU 密集任务？**

- ⭐⭐ | 要点：Python 多进程（`multiprocessing`）；Node `worker_threads`（共享内存）或拆分任务用 `setImmediate` 让出。共同点：都不能在主事件循环里长时间同步计算。
