### **职位名称**：Agent 全栈开发工程师（中级）

**职位概述**：  
我们正在寻找一位中级 AI 开发工程师，改造存量业务系统，打造部门智能体。该岗位需要具备 AI 框架使用经验，能够独立开发和维护 MCP 服务，优化企业内部的自动化流程和决策支持。

---

### **主要职责**：

#### 1. 飞书数据集成与智能体开发

- 利用飞书提供的业务数据接口和开发套件，将飞书内部的数据（如人员、任务、审批等）整合至智能体的工作流中，实现自动化业务处理。
- 通过字段捷径（Fass）和 Node.js，设计并实现智能体的交互逻辑，优化用户体验。
- 基于飞书的业务数据，开发智能体在不同场景下的自动化响应，支持实时数据处理和任务调度。
    
#### 2. AI 应用开发与框架集成
- 使用 AI 框架（如 LangGraph、Pydantic AI、Autogen、CrewL 等）进行智能体的多轮对话和决策优化，提升系统的智能化水平。
- 配合企业业务需求，开发针对不同部门和任务的智能体应用，通过提示词工程和上下文优化，提高智能体的响应效率。
    

#### 3. MCP 服务与客户端开发
- 熟悉并能够独立开发和维护 `mcp-service` 和 `mcp-client`，支持企业多渠道平台的接入与集成。
- 基于 MCP 架构，通过服务端和客户端的双向交互，确保业务数据在飞书平台与其他系统之间的流转。
- 实现 MCP 客户端的与前端系统的无缝对接，优化数据呈现和智能体响应的用户界面。
    

#### 4. 数据存储与管理
- 负责飞书平台与外部数据库（如 Redis、PostgreSQL）和缓存系统（如 pgvector）的集成，确保数据存储高效且安全。
- 支持智能体与全局知识库和个人知识库的集成，实现快速的数据检索和上下文处理。

#### 5. 异步编程与性能优化

- 负责异步任务的设计与实现，确保系统能够处理 I/O 密集型任务，并优化性能。
- 使用 Python 异步框架（如 Asyncio、FastAPI）和 ts 进行高效开发，确保高并发场景下的稳定性和响应速度。

#### 6. AI 模型调优与部署

- 调优并部署 AI 模型，特别是在 LLM（大语言模型）的微调和应用，提升智能体在飞书平台上的应用效果。
- 与 DevOps 团队合作，通过 Docker、Nginx 等工具进行容器化部署，并实现 CI/CD 流程。
    

#### 7. 反馈与持续改进
- 通过飞书平台的用户反馈数据，持续优化智能体的工作流和交互方式。
- 设计并实施反馈回路，不断根据用户行为和业务需求调整系统，提升智能体的响应精度和效率。

---

### **岗位要求**：

#### 技术能力：

1. **编程语言与框架**：
