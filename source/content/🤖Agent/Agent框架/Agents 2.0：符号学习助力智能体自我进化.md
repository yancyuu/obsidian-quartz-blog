## 🌟概述

[github仓库](https://github.com/aiwaves-cn/agents/tree/master?tab=readme-ov-file#overview)

代理符号学习是一个用于训练语言代理的系统框架，其灵感源自用于训练神经网络的联结学习过程。我们将语言代理与神经网络进行类比：代理的代理管道对应于神经网络的计算图，代理管道中的节点对应于神经网络中的层，节点的提示和工具对应于层的权重。通过这种方式，我们能够在使用基于语言的损失、梯度和权重进行代理训练的背景下实现联结学习的主要组成部分，即反向传播和基于梯度的权重更新。

[![](https://github.com/aiwaves-cn/agents/raw/master/assets/overview.png)](https://github.com/aiwaves-cn/agents/blob/master/assets/overview.png)

我们在智能体训练的背景下，通过精心设计的提示流水线实现了损失函数、反向传播和权重优化器。以训练示例为例，我们的框架首先进行“前向传递”（智能体执行），并将每个节点的输入、输出、提示和工具使用情况存储在一个“轨迹”中。然后，我们使用基于提示的损失函数来评估结果，从而得到“语言损失”。之后，我们沿着轨迹将语言损失从最后一个节点反向传播到第一个节点，从而对每个节点内的符号成分进行文本分析和反射，我们称之为语言梯度。最后，我们根据语言梯度，使用另一个精心设计的提示更新每个节点中的所有符号成分，以及由节点及其连接组成的计算图。我们的方法还可以通过将节点视为不同的智能体或允许多个智能体在一个节点上采取行动，自然地支持优化多智能体系统。

## 用 AIWaves Agents 的典型场景（流程可控、可审计）

1. **合规/审计类报告流水线**  
    需求→检索→事实抽取→撰写→法务复核→定稿；每步有明确输入/输出与过线标准，留痕好审计。
    
2. **电商上新 SOP**  
    采集参数→竞品对比→卖点摘要→标题/要点生成→图文检查→上架接口调用；一条龙闭环。
    
3. **工单流转/客服质检**  
    分流→知识库检索→草稿→命中合规词库→升级到人工；节点里挂工具（检索、规则引擎、打标签）。
    
4. **代码改动影响分析与自动化测试**  
    解析 PR→依赖拓扑→风险评估→生成单测→运行 CI→总结结果。
    
5. **门店/运营日检清单（你之前的“店长 Agent”）**  
    拉取库存/销售→异常检测→待办清单→生成日报→推送；每天按固定流程跑。
    
6. **数据标注与质检流水线**  
    预标注→一致性检查→冲突裁决→抽检→回写；可反复复用、沉淀经验做“符号学习”微调提示与节点。
    

**为什么选它**：流程像“装配线”，需要**稳定、可控、可复盘**，还能在真实数据上**持续优化 SOP/提示**。
