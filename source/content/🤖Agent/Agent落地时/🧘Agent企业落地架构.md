### 企业落地Agent应用往往从下面两点开始：
##### 全新开发
从零开始，为一个全新的业务场景或颠覆性的产品构想，原生设计和开发AI应用。这种模式不受历史技术债务的束缚，可以采用最先进的架构，最大化地发挥AI Agent的能力，是实现颠覆式创新的最佳路径。例如，打造一个面向金融行业的AI研究分析师，或者开发一个企业内部的“超级知识入口”。

##### 存量改造
这是绝大多数企业会选择的路径。它指的是在企业现有的、成熟的核心业务系统（如ERP、CRM、SCM）中，嵌入AI Agent的能力，对其进行“智能化升级”。这种方式能直接作用于核心业务流程，价值释放路径更短、更明确。

> **什么时候选 FC**
>- 业务不确定、流量波动大、爆发式增长或长时间低负载。
>- 想快速验证 / 快速迭代，团队人手有限。
>- 以事件驱动为主（HTTP、队列、对象存储触发等）。
>- 需要较强的“沙箱”隔离但不想自建底层。 
> **什么时候选 K8s**
> - 有**强合规/内网**要求（如必须在专有网络、专有集群）。
> - **稳定高负载**、长期运行的服务，想优化单位算力成本。
> - 需要深度自定义：特殊调度（GPU/MIG）、自定义网络/网关、安全策略。
> - 已经有成熟的容器平台与 SRE/平台团队。
