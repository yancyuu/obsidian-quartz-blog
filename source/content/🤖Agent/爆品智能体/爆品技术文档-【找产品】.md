
### 一、系统架构与核心组件

#### 架构设计

系统采用四层架构：

1. **接入层**：标准化 API 接口，对外暴露服务。
    
2. **运行时层**：使用 Agno 的 AgentOS 运行时，负责 agent 调度、会话管理、团队／流程编排。
    
3. **智能体层**：4 个核心 Agent：市场空间分析、竞争格局分析、自身优势评估、决策协调。
    
4. **数据层**：PostgreSQL 作为主存储，与 Agno 存储机制对接（可通过 Agno 支持的外部存储插件、或自定义工具）。

### 二、市场空间分析 Agent 设计

#### 1. 功能设计

市场空间分析 Agent 通过 **人机交互（HITL）** 模式获取用户输入的市场相关信息：

- **数据采集**：通过人机交互方式手动输入关键词，如“品类名称”。
    
- **数据解析**：手动输入市场规模（如单位：元）和同比增长率（如百分比）。
    
- **趋势预测**：根据人工输入的历史数据，手动输入预测的增长趋势。
    
- **热度评估**：通过手动输入平台热度指数。
    

#### 2. 技术实现（按 Agno HITL 最佳实践）

```python
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.tools import BaseTool
from agno.os import AgentOS
from agno.db.postgres import PostgresDb
from agno.tools import tool

# 数据库连接配置
db_url = "postgresql+psycopg://ai:ai@localhost:5532/ai"
db = PostgresDb(db_url=db_url)


@tool(requires_confirmation=True)
def manual_input_market_size() -> str:
    """手动输入市场规模"""
    return input("请输入市场规模（单位：元）：")

@tool(requires_confirmation=True)
def manual_input_growth_rate() -> str:
    """手动输入同比增长率"""
    return input("请输入同比增长率（百分比）：")


# 创建代理与工具
agent = Agent(
    name="MarketSpaceAgent",
    id="market_space_agent",
    model=OpenAIChat(id="gpt-4o-mini", api_key="your_api_key"),
    tools=[manual_input_market_size, manual_input_growth_rate],
    instructions=["分析市场空间信息并记录结果"],
    db=db,
    markdown=True
)

# 创建 AgentOS 实例
agent_os = AgentOS(
    id="agentos-hitl",
    agents=[agent],
)

app = agent_os.get_app()

if __name__ == "__main__":
    agent_os.serve(app="hitl_confirmation:app", port=7777)

```
#### 3. 数据源与处理

1. **市场规模输入**：通过人工交互输入市场规模。
    
2. **同比增长率输入**：通过人工交互输入增长率。
    
3. **存储**：将人工输入的数据存储到 PostgreSQL 数据库中的 `market_space` 表。

### 三、竞争格局分析 Agent 设计

#### 1. 功能设计

竞争格局分析 Agent 通过人工交互获取竞争相关数据：

- **头部品牌**：通过人机交互手动输入头部品牌信息。
    
- **市场份额**：通过人工输入手动填写各品牌市场份额。
    
- **行为模式识别**：通过人工输入，分析竞争品牌的行为模式（是否有封杀行为）。
    

#### 2. 技术实现

```python
@tool(requires_confirmation=True)
def manual_input_brands() -> str:
    """手动输入头部品牌及市场份额"""
    brands = input("请输入头部品牌名称（逗号分隔）：")
    market_share = input("请输入对应品牌的市场份额（逗号分隔，百分比）：")
    return f"品牌：{brands}，市场份额：{market_share}"

# 创建竞争格局分析 Agent
competition_agent = Agent(
    name="CompetitionAgent",
    id="competition_agent",
    model=OpenAIChat(id="gpt-4o-mini", api_key="your_api_key"),
    tools=[manual_input_brands],
    instructions=["分析竞争格局并输出市场份额"],
    db=db,
    markdown=True
)

# 创建 AgentOS 实例
agent_os = AgentOS(
    id="agentos-hitl",
    agents=[competition_agent],
)

app = agent_os.get_app()

if __name__ == "__main__":
    agent_os.serve(app="hitl_confirmation:app", port=7777)


```
#### 3. 数据源与处理

- **头部品牌与市场份额**：通过人工输入头部品牌及其市场份额。
    
- **存储**：将输入的数据存储到 PostgreSQL 数据库中的 `competition` 表。

### 五、决策协调 Agent 设计

#### 1. 功能设计

决策协调 Agent 负责将人工输入的市场数据整合并给出建议：

- **整合评分**：根据人工输入的三维评分（市场空间、竞争格局、自身优势）进行加权综合评分。
    
- **进入建议**：基于评分生成进入建议（例如：优先进入、谨慎进入、放弃）。
    
- **报告输出**：通过人工输入生成报告输出。
    

#### 2. 技术实现

```python
@tool(requires_confirmation=True)
def manual_input_decision() -> str:
    """手动输入决策评分"""
    market_score = input("请输入市场空间评分：")
    competition_score = input("请输入竞争格局评分：")
    advantage_score = input("请输入自身优势评分：")
    return f"评分：市场空间：{market_score}，竞争格局：{competition_score}，自身优势：{advantage_score}"

# 创建决策协调 Agent
decision_agent = Agent(
    name="DecisionAgent",
    id="decision_agent",
    model=OpenAIChat(id="gpt-4o-mini", api_key="your_api_key"),
    tools=[manual_input_decision],
    instructions=["生成市场进入建议及报告"],
    db=db,
    markdown=True
)

# 创建 AgentOS 实例
agent_os = AgentOS(
    id="agentos-hitl",
    agents=[decision_agent],
)

app = agent_os.get_app()

if __name__ == "__main__":
    agent_os.serve(app="hitl_confirmation:app", port=7777)

```
#### 3. 数据源与处理

- **评分输入**：通过人工输入综合评分。
    
- **决策输出**：基于评分生成进入建议。
    
- **存储**：将评分及决策结果存储到 PostgreSQL 数据库中的 `decision` 表。

### 六、系统部署方案

### 七、应用场景与价值

- **新品类拓展**：帮助企业快速识别并验证潜在市场机会，降低试错成本。
    
- **现有品类优化**：分析现有品类的市场潜力与竞争态势，指导品类优化策略。
    
- **战略决策支持**：为企业的长期战略提供数据支持，帮助企业在 AI 时代保持竞争优势。
    
- **价值体现**：
    
    - 提高决策效率：通过自动化数据采集与分析，将原本需要数周的市场机会评估缩短至数小时。
        
    - 降低决策风险：基于多维度分析与加权决策，减少主观判断带来的决策偏差。
        
    - 支持战略创新：通过 AI 驱动的市场机会识别，帮助企业发现传统方法难以识别的创新机会。
        
    - 实现数据驱动：将分散在不同渠道的数据整合为统一的市场机会评估报告，支持数据驱动的决策。
