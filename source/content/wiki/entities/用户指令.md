# 用户指令

## 基本信息
- Type: other
- Source: [[sources/drawing-2025-12-16-16-29-09-excalidraw_826da0|Drawing 2025-12-16 16.29.09.excalidraw]]

## 描述
用户指令是架构图中用户层的核心输入，代表终端用户向 Agent 系统发出的原始需求或问题。它是整个 Agent 工作流的起点，触发中控大脑进行[[concepts/意图识别与路由|意图识别与路由]]，进而驱动[[concepts/任务规划器|任务规划器]]生成执行计划。用户指令的质量和明确程度直接影响 Agent 系统的响应效果，是评估系统意图理解能力的重要输入指标。
