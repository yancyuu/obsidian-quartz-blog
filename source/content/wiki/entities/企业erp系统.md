# 企业ERP系统

## 基本信息
- Type: product
- Source: [[sources/drawing-2025-12-16-16-29-09-excalidraw_826da0|Drawing 2025-12-16 16.29.09.excalidraw]]

## 描述
企业 ERP 系统是 Agent 架构图中工具层的核心企业级组件，代表了 Agent 系统与组织内部业务数据的接口。它被设计为中控大脑可以调用的外部系统之一，使得 Agent 能够访问企业的订单、库存、客户等核心业务数据。在该架构中，企业 ERP 系统的接入使得整个 Agent 系统从通用的 AI 助手转变为企业级业务自动化平台。
