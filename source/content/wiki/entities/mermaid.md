# Mermaid

## 基本信息
- Type: product
- Source: [[sources/🚀-爆款-ai-agent-公众号文章写作指南_44ecbb|🚀 爆款 AI Agent 公众号文章写作指南]]

## 描述
Mermaid 是一种基于文本的图表描述语言，允许用户通过编写简洁的代码来生成流程图、序列图、甘特图等多种可视化图表。在 AI Agent 主题的公众号文章写作中，Mermaid 被强烈推荐为展示 Agent 业务重构流程的核心工具。作者主张用 Mermaid 绘制 SOP 进化图，取代大段代码，使非技术背景的决策者（如老板）能够直观理解 Agent 如何优化业务流程。文章还提到可以为 Mermaid 流程图优化配色和样式代码，使其呈现"商业咨询范儿"，提升文章的专业感和说服力。
