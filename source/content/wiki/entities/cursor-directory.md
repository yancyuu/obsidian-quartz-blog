# Cursor Directory

## 基本信息
- Type: product
- Source: [[sources/cursor提示词_bf3f6f]]

## 描述
Cursor Directory 是一个提供 AI 编码助手 Prompt 配置模板的在线资源平台，网址为 [cursor.directory](https://cursor.directory/)。它为开发者提供了结构化的系统提示词模板，用于配置 Cursor 编辑器中的 AI 编码助手行为。本文档以 Cursor Directory 为参照模型，为两类不同的开发智能体——代码编写智能体和代码阅读智能体——分别定义了专用的系统 Prompt，体现了将工程规范与 AI Agent 配置相结合的实践方法。通过这种参照关系，Cursor Directory 成为 [[concepts/专用prompt|专用prompt]] 和 [[concepts/通用prompt库|通用prompt库]] 设计的重要灵感来源，代表了行业内 Prompt 工程化的典型范式。
