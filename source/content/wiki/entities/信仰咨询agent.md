# 信仰咨询Agent

## 基本信息
- Type: project
- Source: [[sources/01-把信仰交给-ai-的血泪教训_558fff|01-把信仰交给-ai-的血泪教训_558fff]]

## 描述
信仰咨询Agent 是作者团队开发的一个面向特定信仰社群的咨询智能体项目，也是文章中揭示的"Agent落地五个致命大坑"中第一个致命大坑的真实案例。该Agent在处理宗教教义相关问题时，大语言模型（LLM）内置的"普世价值观"与特定信仰社群的核心教义产生了严重冲突。Agent试图用世俗、理性化的语言去解释信仰问题，结果给出的答案直接违背了教派的核心教义，引发了社区的强烈不满。这个案例深刻揭示了Agent在涉及宗教、政治等敏感话题时价值观失控的风险，促使作者建立了[[concepts/双层白名单|双层白名单]]与三段式兜底的修复方案。该项目证明了一个关键教训：仅靠Prompt提示无法有效约束Agent的行为边界，必须通过代码层面将禁区写死。
