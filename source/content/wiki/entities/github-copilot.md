# GitHub Copilot

## 基本信息
- Type: product
- Source: [[sources/2025-0312-💆copilot和agent的区别_750b52|2025-0312-💆copilot和agent的区别_750b52]]

## 描述
GitHub Copilot 是一款由 GitHub 推出的 AI 编程辅助工具，属于典型的 Copilot（副驾）类型产品。其核心定位是面向人类的智能助手，辅助开发者执行代码补全和输入提示等具体编程任务。技术上，它基于 Prompt 工程和模型调用实现，不具备显式规划器或强自治性，主要依赖人类触发来响应。在 Copilot 与 Agent 的范式对比中，GitHub Copilot 常被用作 Copilot 范式的代表案例，与 [[entities/autogpt|AutoGPT]]、[[entities/langgraph|LangGraph Agent]] 等 Agent 类产品形成鲜明对比。
