## 描述
Claude Skills 是 [[entities/anthropic|Anthropic]] 最近发布的一项产品功能，其核心机制为"渐进式披露"（Progressive Disclosure），旨在帮助 Agent 管理[[concepts/上下文窗口压力|上下文窗口压力]]。该功能在发布后被部分人宣传为 Agent 领域的"工业革命"，但在来源文章中遭到作者严厉批评。作者认为 Claude Skills 本质上只是[[concepts/手动分页|手动分页]]（Manual Paging）的换皮之作，并未解决上下文窗口的根本缺陷。文章将其比喻为"把说明书锁在柜子里，用的时候才去拿"，导致 Agent 变成了图书管理员，大量时间浪费在找资料上而非处理任务本身，最终使 Agent 变得更慢、更碎片化。
