# 标签分析Agent

## 基本信息
- Type: project
- Source: [[sources/07-我如何用-agent-砍掉团队30的“垃圾时间”_d98060|07-我如何用-agent-砍掉团队30的"垃圾时间"]]

## 描述
标签分析Agent是VOC舆情分析系统中专门负责标签体系维护的子Agent。它会定期分析未被分类的评论数据，主动建议新的标签类别，从而保持标签体系的动态生长。该Agent解决了旧标签体系扁平化、标准不统一导致数据无法量化分析的问题，使标签从静态的人工定义转变为动态的智能演化。新生成的标签采用结构化格式（如`性能/加载速度`、`UI/交互逻辑`），便于后续的数据量化与多维分析。标签分析Agent与[[entities/标签选择Agent|标签选择Agent]]协同工作，并通过[[entities/飞书|飞书]]平台进行数据同步与通知推送，共同构成了完整的VOC标签智能管理体系。
