# Web Search

## 基本信息
- Type: product
- Source: [[sources/drawing-2025-12-16-16-29-09-excalidraw_826da0]]

## 描述
Web Search 是该 Excalidraw 架构图中工具层的核心组件之一，作为 Agent 系统获取外部实时信息的重要工具。它被设计为中控大脑可以调用的外部能力之一，与 Python 解释器、企业 ERP 系统等并列。在该架构中，Web Search 为信息检索 Agent（Agent A）提供了关键的数据获取能力，使得整个系统能够访问互联网上的最新信息，从而补充长期记忆中可能缺失的实时性内容。
