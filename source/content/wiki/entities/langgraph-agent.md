## 基本信息
- Type: project

## 描述
LangGraph Agent 是基于 [[entities/langgraph|LangGraph]] 框架构建的自主智能体（Agent）实现方案，在 Copilot 与 Agent 的对比讨论中被列为 Agent 范式的典型示例之一。它具备完整的感知—推理—决策—执行闭环，通常配备 planner、router、task scheduler 等核心组件，并支持短期与长期记忆以及状态持久化。与 Copilot 类产品形成鲜明对比，LangGraph Agent 强调强自治性和多工具协同能力，能够自主规划和执行复杂的多步骤任务。它与 [[entities/autogpt|AutoGPT]]、[[entities/openagents|OpenAgents]] 等项目同属自主智能体生态。
