# 订餐Agent

## 基本信息
- Type: project
- Source: [[sources/01-把信仰交给-ai-的血泪教训_558fff|01-把信仰交给-ai-的血泪教训_558fff]]

## 描述
订餐Agent是作者团队开发的一个面向餐饮订餐场景的Agent项目，也是文章中第二个"致命大坑"的核心案例。该项目在落地过程中暴露出两个严重问题：其一，网络抖动导致Agent自动重试，系统后台生成了两个完全相同的待支付订单，造成资源污染与用户选择困难；其二，用户在对话中修改购物车数量后，价格计算服务与库存校验服务之间的状态出现了不一致。这些问题的出现促使作者引入了幂等键机制、订单原子化操作以及补偿链方案，并由此强调了一个关键认知——Agent的核心价值在于**构建**订单，而非**支付**订单。
