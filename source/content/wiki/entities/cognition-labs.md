## 描述
Cognition-labs（又称 Cognition AI）是一家专注于构建自主 AI 软件工程师的公司，其核心产品为 [[entities/devin|Devin]]——一个被誉为首个完全自主 AI 软件工程师的 Agent 系统。该组织代表了当前 Agent 领域中追求高自主执行能力的工程派方向，其产品设计理念强调在沙盒环境中赋予 Agent 较高自治权的同时保持明确的安全边界。在 Agent 自主性光谱中，Cognition-labs 的方案被归类为"中高自主 + 明确沙盒权限"的典型工程型案例，与强调 [[concepts/human-in-the-loop|Human-in-the-loop]] 的低自主模式形成对比。Devin 的推出在业界引发了关于 Agent 自主性与人类控制之间平衡点的广泛讨论。
