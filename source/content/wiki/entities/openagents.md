# OpenAgents

## 基本信息
- Type: project
- Source: [[sources/2025-0312-💆copilot和agent的区别_750b52|2025-0312-💆copilot和agent的区别_750b52]]

## 描述
OpenAgents 是一个开源的自主 AI Agent 项目，在相关资料中被列为 Agent 范式的示例实现之一。它与 [[entities/langgraph|LangGraph]] Agent 等项目类似，具备任务链、规划器和工具管理等核心能力，强调强自治性和自主感知环境与决策执行的能力。OpenAgents 属于被归类为"声称是 Agent"的产品类别，与 Copilot 类被动辅助型产品形成鲜明对比，体现了从被动工具辅助向主动自主决策演进的技术趋势。
