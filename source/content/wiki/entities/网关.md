# 网关

## 基本信息
- Type: product
- Source: [[sources/基于-iam-的网关鉴权系统设计文档_78626b|基于 IAM 的网关鉴权系统设计文档]]

## 描述
网关是该架构中所有 API 请求的统一入口和流量调度枢纽。它负责接收前端请求、解析 Token 获取用户标识、提取 API 路径，并作为中间方与 [[entities/iam系统|IAM系统]] 交互获取权限信息后执行鉴权。网关根据鉴权结果决定请求的路由去向：有权限则转发至对应 [[entities/业务系统|业务系统]]，无权限则直接返回 403。这种设计将安全校验逻辑从业务系统中剥离出来，实现了统一的访问控制。
