# 飞书

## 基本信息
- Type: product
- Source: [[sources/07-我如何用-agent-砍掉团队30的“垃圾时间”_d98060|07-我如何用-agent-砍掉团队30的"垃圾时间"]]

## 描述
飞书是字节跳动旗下的企业协作平台，在本文中作为 VOC 舆情分析系统的核心集成层使用。作者没有开发独立的后台管理系统，而是直接通过飞书 API 将清洗后的数据写入飞书多维表格，使运营人员能在手机端接收"严重舆情报警"并直接回复处理。在该 Agent 架构中，飞书扮演"嘴"的角色——即信息输出与团队协作的最后一公里。这一设计有效规避了"没人爱登录独立后台"的采用率问题，将系统能力直接嵌入团队已有的工作流中。
