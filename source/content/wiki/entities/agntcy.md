# AGNTCY

## 基本信息
- Type: organization
- Source: [[sources/2025-0426🧘以人为中心的agent_d84722|2025-0426🧘以人为中心的agent_d84722]]

## 描述
AGNTCY 是一个致力于推动智能体标准化通信的联盟组织。该联盟的核心理念是将 [[concepts/mcp|MCP]]（Model-Context-Protocol）打造为"智能体时代的 HTML"，通过标准化协议来简化[[concepts/多智能体协作|多智能体协作]]中的通信复杂度。AGNTCY 的愿景类似于互联网中 TCP/IP 协议的作用，旨在统一多 Agent 系统之间的通信标准，使 Agent 与工具之间的连接更加通用化和规范化。该联盟与 [[entities/glean|Glean]]、LangChain 等生态参与者共同推动 Agent 通信协议（包括 [[concepts/mcp|MCP]] 和 [[concepts/a2a|A2A]]）的普及与落地。
