## 描述
PowerShell 是微软开发的命令行外壳程序和脚本环境，广泛应用于 Windows 系统的管理与自动化操作。在文章的实测中，[[entities/gpt-5-2|GPT-5.2]] 在执行论文分析任务时反复尝试使用 PowerShell 运行命令，但因脚本过长导致终端不支持而持续报错，暴露了 [[entities/gpt-5-2|GPT-5.2]] 在命令行环境适配方面的严重缺陷。作者将 [[entities/gpt-5-2|GPT-5.2]] 与 PowerShell 搏斗的过程描述为一个典型的翻车案例。相比之下 [[entities/gemini-3-pro|Gemini 3 Pro]] 直接用简洁的 Python 脚本就完成了同样的任务。
