# Magentic-UI

## 基本信息
- Type: project
- Source: [[sources/2025-0426🧘以人为中心的agent_d84722|2025-0426🧘以人为中心的Agent]]

## 描述
Magentic-UI 是微软推出的一个人机协同智能体项目，核心理念是"以人为中心"，旨在让人类与 AI 在任务执行过程中更高效地配合。该项目基于微软 [[concepts/agent|智能体]] 框架 AutoGen 下的 Magentic-One 系统适配而来，底层由四个专门化智能体组成团队：协调器（Orchestrator）、网络浏览器（WebSurfer）、编码器（Coder）和文件浏览器（FileSurfer）。Magentic-UI 支持[[concepts/多智能体协作|多智能体协作]]模式下的协同规划、实时协同执行、安全防护机制以及计划的学习与重用等核心功能。用户可以在执行前编辑计划、随时接管操作，并对关键操作进行审批确认，充分体现了[[concepts/agent|智能体]]设计中[[concepts/copilot-+-agent-融合架构|人机协同]]的理念。
