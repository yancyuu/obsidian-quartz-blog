# 版式识别

## 基本信息
- Type: other

## 描述
版式识别（Layout Analysis）是文档处理中的一项关键技术，用于识别和提取文档中的结构化信息，如表格、段落、标题等。在卤味零售项目中，客户大量使用 Excel 价格表和排班表，直接将 Excel 转为纯文本会导致表格结构完全破碎，大模型无法正确理解。

架构师通过版式识别技术将表格从文档中切出，并转为 Markdown 或 JSON 格式，再单独建立索引，从而让大语言模型能够正确解析和检索表格内容。这是 [[concepts/混合检索|混合检索]]、[[concepts/意图路由|意图路由]] 等策略之外，RAG 落地中数据预处理阶段不可或缺的环节。在处理复杂企业文档（尤其是含大量结构化表格的零售、财务场景）时，版式识别是保证数据质量的基础能力。
