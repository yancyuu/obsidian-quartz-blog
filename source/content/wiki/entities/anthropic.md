## 描述
Anthropic 是一家专注于 AI 安全与研究的公司，同时也是 Claude 系列 AI 产品的开发者。其推出的 [[entities/claude-4-5|Claude 4.5]] 等模型在业界具有广泛影响力。在本文中，Anthropic 最近发布了 **Claude Skills** 功能，被一些人吹捧为 Agent 的"工业革命"。然而，作者对 Anthropic 的这一发布持强烈批评态度，认为 Anthropic 给出的不过是一个类似 DOS 操作系统的方案——内存有限，需要靠插软盘（即 Skills）来弥补。文章暗示 Anthropic 在用营销词汇掩盖 Agent 上下文窗口受限的技术本质缺陷。
