# 业务系统

## 基本信息
- Type: other
- Source: [[sources/基于-iam-的网关鉴权系统设计文档_78626b|基于 IAM 的网关鉴权系统设计文档]]

## 描述
业务系统是网关鉴权通过后的请求实际处理方。它接收[[entities/网关|网关]]转发的 API 请求，执行具体的业务逻辑操作，并将处理结果通过网关返回给前端。在该架构中，业务系统无需关心权限校验逻辑，只需专注于业务功能的实现，这得益于网关层前置的[[entities/iam系统|IAM系统]]统一鉴权设计。这种职责分离的架构体现了[[concepts/核心逻辑剥离|核心逻辑剥离]]的设计理念，使业务系统能够保持高内聚、低耦合的工程特性。
