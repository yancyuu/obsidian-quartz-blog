## 描述
TaskWeaver 是一个被归类为 [[concepts/agent|Agent]] 类别的 AI 项目，在 Copilot 与 Agent 区别的市场现状分析中被提及。它被描述为具备任务链、规划器和工具管理能力，属于声称是 Agent 的产品之一。与 [[entities/autogpt|AutoGPT]] 和 AgentGPT 类似，TaskWeaver 的核心特征是具备自主任务规划和执行能力，而非仅仅作为人类交互的被动辅助工具。它代表了当前 AI Agent 领域中一类强调自主性与工具调用能力的产品方向。
