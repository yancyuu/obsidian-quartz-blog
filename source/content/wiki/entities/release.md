# release

## 基本信息
- Type: other
- Source: [[sources/分支管理_563fba|分支管理]]

## 描述
release 是项目中的正式发布分支，仅接受已通过测试和验收的开发或修复分支的合并。在该分支上会统一打上 Tag 进行版本发布，是版本管理与问题回溯的重要基础，支持快速回滚至历史稳定版本。发布完成并回归测试无误后，release 分支的内容需要合并至 master 分支。在多分支并行场景中，release 分支的代码也需要及时同步到 master，以保证后续分支能获取最新代码。
