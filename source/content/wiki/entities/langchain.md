## 描述
LangChain 是 Agent 生态中重要的技术组织，致力于推动智能体通信与协作的标准化。该组织推出了 Agent Protocol，为 Agent 与工具之间的通信提供了标准化协议方案。在 [[concepts/mcp|MCP]]（模型上下文协议）生态建设中，LangChain 也积极参与，与 [[entities/glean|Glean]]、AGNTCY 等组织共同推动智能体通信标准的建立。在 [[concepts/多智能体协作|多智能体协作]]领域，LangChain 提供的协议和工具链帮助开发者实现标准化的 Agent 架构与通信机制。
