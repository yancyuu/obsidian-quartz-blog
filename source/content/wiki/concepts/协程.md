# 协程

## 定义
协程是一种用户态的、可暂停恢复的函数。通过 `async def` 定义，调用时返回协程对象而非立即执行。其底层是基于生成器（yield）的状态机实现。与线程相比，协程由事件循环在用户态调度，切换开销极小，适用于单线程内的 IO 密集型并发任务。但协程中不能运行 CPU 密集型代码，否则会阻塞整个事件循环。

## 关键特征
- **用户态调度**：协程的切换不涉及操作系统内核态转换，完全由用户态的事件循环管理，上下文切换开销极小。
- **可暂停恢复**：协程函数在执行过程中可通过 `await` 关键字暂停自身，将控制权交还给事件循环，等待结果就绪后恢复执行。
- **惰性执行**：通过 `async def` 定义的协程函数在被调用时不会立即执行函数体，而是返回一个协程对象，需被事件循环调度或通过 `await` 驱动才能执行。
- **单线程并发**：协程运行在单一线程内，适用于 IO 密集型任务的并发处理，但不适用于 CPU 密集型代码，否则会阻塞整个事件循环。
- **基于生成器实现**：底层依赖生成器（yield）机制构建状态机，实现协程的暂停与恢复语义。

## 应用
- **高并发网络服务**：如异步 Web 框架（FastAPI、aiohttp），利用协程高效处理大量并发 HTTP 请求。
- **异步 IO 操作**：文件读写、数据库查询、网络请求等 IO 密集型场景，通过协程避免线程阻塞带来的资源浪费。
- **实时通信系统**：WebSocket、聊天服务器等需要维持大量长连接的应用。
- **爬虫与数据采集**：并发抓取多个页面，大幅提升采集效率。
