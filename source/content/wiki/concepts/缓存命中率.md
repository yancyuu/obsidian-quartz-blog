# 缓存命中率

## 定义
缓存命中率是衡量 Prompt Caching 效果的关键指标，指请求中成功命中已有缓存前缀的比例。开发者可通过检查 API 响应中的 `cache_read_input_tokens` 或 `cached_tokens` 字段来确认是否真正命中。命中率越高，说明前缀复用越有效，成本和延迟节省越显著。

## 关键特征
- **量化指标**：以百分比形式反映缓存前缀被成功复用的请求比例。
- **响应字段验证**：可通过 API 响应中的 `cache_read_input_tokens` 或 `cached_tokens` 字段直接确认缓存命中情况。
- **成本直接关联**：命中率越高，前缀命中带来的成本节省（50%~90%）和延迟降低越显著。
- **依赖前缀一致性**：命中率高低取决于请求间共享前缀的稳定性和长度。

## 应用
- **大模型推理优化**：在 LLM 推理服务中监控缓存命中率，评估 Prompt Caching 的实际效果。
- **成本治理**：通过追踪命中率指标，优化 Prompt 结构设计，最大化前缀复用率，降低 API 调用成本。
- **性能调优**：将缓存命中率作为延迟优化的核心观测指标，指导推理系统的缓存策略调整。
