# 分级策略

## 定义
分级策略是一种针对大模型接口调用成本与延迟问题的工程优化方法。其核心思想是根据输入数据（如用户评论）的复杂程度，将请求路由到不同的处理路径：简单或重复的输入走轻量级通道（缓存查询、正则匹配），仅将复杂输入才交给大语言模型（LLM）处理，从而在保证处理质量的前提下大幅降低算力成本。

## 关键特征
- **按复杂度路由**：依据输入内容的长度、重复度或语义复杂度进行分级，动态选择处理通道。
- **多层级降本机制**：从最廉价的缓存命中（如 GPTCache）、到正则/规则匹配、再到昂贵的 LLM 调用，形成成本递增的处理阶梯。
- **吞吐量提升**：通过过滤大量简单请求，显著减少对昂贵 LLM 接口的并发压力，提升系统整体吞吐能力。
- **可组合性**：常与并行处理机制结合使用，例如在调用大模型的同时并行执行翻译与分类任务，进一步压缩端到端延迟。

## 应用
- **舆情分析系统**：处理海量用户评论时，对高频的简单评价（如"好评"、"不错"）直接走缓存返回标签，针对包含复杂情感的长篇差评才调用大模型进行深度解析。
- **智能客服路由**：识别用户意图复杂度，简单咨询走 FAQ 知识库检索，复杂投诉交由 Agent 处理。
- **大规模数据处理管道**：在需要对海量非结构化数据进行结构化提取的场景中，利用分级策略控制整体 API 调用预算。
