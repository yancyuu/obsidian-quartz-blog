# 外星神器的触手

## 定义
「外星神器的触手」是对 Agent 系统中**工具层**的生动隐喻，源自该 Excalidraw 架构图。它将 Agent 系统的外部工具集成能力比喻为神话中外星生物延伸出的触手，强调工具层作为 Agent 能力延伸通道的扩展性与多功能性——正如触手可以向各个方向伸展一样，Agent 系统通过工具层可以连接各种外部系统和服务，从而获得感知、计算、数据访问等多元能力。

## 关键特征
- **能力延伸性**：触手象征着 Agent 核心能力向外部世界的延伸，每个工具代表一种新的能力维度
- **多向连接**：如同触手可同时伸向不同方向，工具层支持 Agent 同时对接多种异构外部系统
- **模块化可插拔**：各触手（工具）相互独立，可按需增减，不影响 Agent 核心架构
- **隐喻一致性**：与同一架构图中将 Agent 中枢比喻为「外星神器」的视觉叙事保持统一，形成完整的意象体系

## 应用
- **Agent 架构设计**：在设计 Agent 系统时，用此隐喻帮助团队理解工具层的设计理念——工具即能力的延伸
- **架构图可视化**：在架构图中以触手状图形表示工具连接，使非技术人员也能直观理解 Agent 与外部工具的协作关系
- **能力规划**：根据业务需求规划需要接入哪些「触手」（如搜索、代码执行、企业数据系统等），以确定 Agent 的能力边界
