# 用户态调度

## 定义
用户态调度是指在用户空间（而非操作系统内核）管理任务的调度和切换机制。在这种调度模式下，任务的创建、挂起、恢复和切换均由运行时库或框架（如事件循环）在用户态完成，无需陷入内核态，从而大幅降低了调度开销。

## 关键特征
- **切换开销极小**：任务切换时只需保存少量寄存器状态（如指令指针、栈指针），无需进行内核上下文切换
- **无需内核介入**：调度逻辑完全运行在用户空间，不依赖操作系统的调度器
- **由事件循环驱动**：通常由事件循环（Event Loop）负责管理和调度协程的执行顺序
- **协作式调度**：任务主动让出执行权（如遇到 I/O 操作时），而非被抢占式调度
- **高并发能力**：由于开销极小，可以在单线程内同时调度大量任务，是实现高并发的关键机制

## 应用
- **协程调度**：在 Python asyncio、JavaScript 等异步编程模型中，协程的调度和切换完全在用户态完成
- **高并发网络服务**：用于构建能够同时处理海量连接的异步 I/O 服务器，如 Web 框架、代理服务器
- **异步 I/O 框架**：配合 I/O 多路复用技术，在等待 I/O 时切换到其他就绪任务，最大化 CPU 利用率
