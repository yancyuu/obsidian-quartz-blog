# Skill Registry

## 定义
Skill Registry（技能注册表）是[[concepts/可逃逸架构|可逃逸架构]]中上下文管理模块的核心组件。其关键设计原则是「仅包含技能名，无工具定义」，注册表充当技能的索引目录而非完整定义仓库。这种设计使得 Agent 运行时保持轻量和无状态，只有在实际需要执行某个技能时才动态加载对应的工具定义。该机制是实现「Stateless Context」和避免上下文污染的基础。

## 关键特征
- **仅含技能名**：注册表中只维护技能的名称和索引，不包含完整的工具定义
- **运行时动态加载**：工具定义在实际执行技能时才被加载到上下文中（Load Tools at Runtime）
- **无状态上下文**：支撑 Stateless Context 设计，Agent 运行时保持轻量
- **避免上下文污染**：通过延迟加载工具定义，防止无关技能描述占据上下文窗口
- **查库存激活模式**：按需激活特定技能时，通过「查库存」方式从注册表检索并加载

## 应用
- **Agent 中控大脑架构**：作为 Agent 中枢系统的技能索引层，配合[[concepts/路由架构与按需加载|路由架构与按需加载]]实现按需调度
- **上下文窗口压力缓解**：在技能数量众多的场景下，有效降低[[concepts/8k挑战|8k挑战]]带来的上下文窗口压力
- **企业级 Agent 部署**：支持大规模技能集管理，同时保持 Agent 运行时的轻量性
- **可演化智能体系统**：技能可独立注册、更新和替换，无需修改 Agent 核心逻辑
