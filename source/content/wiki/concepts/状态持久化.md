# 状态持久化

## 定义
状态持久化是一种技术方法，指智能体（Agent）能够在运行过程中保存其内部状态（包括短期记忆和长期记忆），使其在多次交互或长时间运行中保持上下文的连贯性。这是 Agent 区别于 Copilot 的关键技术能力之一。

## 关键特征
- **短期与长期记忆**：支持 Agent 存储并管理短期工作记忆和长期持久化记忆
- **上下文连贯性**：在多次交互或长时间运行中保持对话和任务的上下文连续不断
- **Agent 核心能力**：是 Agent 技术结构的重要特征，区别于通常仅具备短期上下文能力的 Copilot
- **高级功能支撑**：为任务流程管理、环境状态读取、多工具协同等高级功能提供基础支持

## 应用
- **长时间任务执行**：在需要跨多个步骤、长时间运行的复杂任务中保持状态不丢失
- **多轮交互场景**：在用户与系统的多次对话中维持上下文连贯性
- **任务流程管理**：支持 Agent 跟踪和管理复杂工作流的执行进度
- **环境状态读取**：使 Agent 能够读取和记忆外部环境的状态信息
- **多工具协同**：在调用多个工具完成任务时，持久化中间结果和执行状态
