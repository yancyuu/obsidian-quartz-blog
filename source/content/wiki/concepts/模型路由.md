## 关键特征
- **容灾切换**：当主模型服务（如 OpenAI）出现故障时，自动切换至备用服务（如 Azure、国产模型），保障业务连续性
- **屏蔽底层差异**：上层 Agent 应用通过统一接口访问模型，无需感知底层模型的具体提供方与切换逻辑
- **负载分配**：在多个模型实例之间进行流量分配，优化资源利用率和响应性能
- **统一出口**：作为企业所有 Agent 访问模型服务的唯一通道，实现集中管控
- **按复杂度分流**：根据请求复杂度将流量路由到不同能力的模型（如 70% 流量走 7B 小模型），大幅降低推理成本
- **语义路由**：基于请求的语义意图进行智能分流，将简单确定性指令导向低成本处理路径（小模型或规则引擎），将复杂推理请求路由至大型 LLM
- **状态机约束**：配合确定性的状态机约束模型的行动空间，避免不必要的 LLM 调用

## 应用
- 企业级 AI 架构中，通过 AI 网关统一管理多个模型服务的接入与切换
- 多云/多供应商场景下的模型服务容灾，避免单一供应商锁定风险
- Agent 运行时在调用模型时，无需关注底层模型是否可用，由网关层透明处理切换
- 客服 Agent 场景中，根据意图复杂度将"修改密码"等确定性指令路由至小模型或规则引擎，避免 GPT-4 的高额 Token 开销
- 结合语义缓存与模型路由的联合策略，实现单次会话成本降低 85%+ 的降本目标
