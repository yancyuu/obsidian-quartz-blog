# 双模执行架构

## 定义
双模执行架构是企业在存量改造（Legacy Modernization）场景中解决黑盒系统对接问题的方案，核心理念是"可控+可伸缩+解耦"。它包含API通道（快模式）和RPA通道（慢模式/异步）两条执行路径：API通道对接现代化系统，RPA通道利用容器化环境结合视觉模型（LVM）对老旧系统进行非侵入式操作。Agent Runtime 直接负责快慢双模的执行选择，使企业无需全面改造旧系统即可嵌入 AI Agent 能力。

## 关键特征
- **双通道执行**：同时支持 API 通道（快模式，同步实时）与 RPA 通道（慢模式，异步操作），根据目标系统特征自动选择路径。
- **非侵入式操作**：RPA 通道通过视觉模型（LVM）对老旧黑盒系统进行操作，无需修改原系统代码或接口。
- **可控 + 可伸缩 + 解耦**：架构设计遵循三大核心理念，保证执行过程的可控性、系统的可扩展性以及新旧系统间的松耦合。
- **Agent Runtime 统一调度**：由 Agent 运行时层负责快慢双模的执行选择与路由，对上层 Agent 透明。
- **存量友好**：企业无需等待旧系统全面改造完成，即可在混合环境中嵌入 AI Agent 能力。

## 应用
- **企业存量系统智能化**：在保留老旧核心业务系统（如传统 ERP、大型机系统）运行的前提下，通过 RPA 通道实现 AI Agent 对旧系统的读写操作。
- **混合环境集成**：在现代化云原生系统与传统本地系统并存的混合 IT 环境中，统一由 AI Agent 完成跨系统业务流程编排。
- **渐进式系统改造**：支持企业从 RPA 通道（非侵入）逐步过渡到 API 通道（原生集成），实现存量系统的分阶段现代化。
