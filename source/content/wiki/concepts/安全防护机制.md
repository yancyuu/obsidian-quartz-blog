# 安全防护机制

## 定义
安全防护机制是 [[entities/autogen|AutoGen]] 旗下 [[concepts/以人为中心的agent|以人为中心的Agent]] 产品 Magentic-UI 中确保用户掌控关键决策的安全设计。对于被认定为重要的操作，系统会通过"批准/拒绝"按钮请求用户许可；用户也可以配置系统对所有操作都请求批准。该机制防止 Agent 在未经用户确认的情况下执行不可逆或高风险操作（如删除数据），是以人为中心设计原则中"重要的决定必须由用户拍板"的工程实现。

## 关键特征
- **重要操作拦截**：系统自动识别高风险或不可逆操作（如删除数据），在执行前暂停并请求用户确认。
- **批准/拒绝交互**：通过明确的"批准/拒绝"按钮呈现给用户，让用户对关键决策拥有最终决定权。
- **可配置审批粒度**：用户可选择仅对重要操作请求批准，也可配置为对所有操作均请求批准，实现安全性与效率的灵活平衡。
- **风险预警与提醒**：Agent 在检测到高风险意图时，不会直接执行，而是先明确提醒用户潜在后果。

## 应用
- **数据删除保护**：当 Agent 发现用户要求删除一批数据时，不会直接执行，而是先明确提醒用户并获得确认后才操作。
- **敏感操作网关**：在文件修改、系统配置变更、资金交易等高风险场景中充当安全关卡，防止 Agent 自主执行不可逆动作。
- **自主性调节**：结合 [[concepts/自主性光谱|自主性光谱]]，用户可根据信任程度调整 Agent 的自主操作范围，从"全手动批准"到"仅高风险确认"灵活切换。
