# 技能注册表/Skill Registry（仅包含技能名）

## 定义
这是一种特殊的技能注册表设计方法，其核心原则是注册表中仅存储技能名称而不包含任何工具定义。这一设计是[[concepts/可逃逸架构|可逃逸架构]]的关键创新之一，旨在从源头消除[[concepts/上下文污染|上下文污染]]问题。传统的技能注册方式会将工具的完整定义（包括参数、描述、[[concepts/json-schema|JSON Schema]]等）全部预加载到上下文中，导致上下文窗口膨胀。而仅包含技能名的注册表将工具定义推迟到运行时[[concepts/路由架构与按需加载|按需加载]]，配合[[concepts/l1-router|意图识别模块]]完成技能匹配后再动态拉取对应的工具 Schema，从而保持意图识别阶段的[[concepts/pure-intent|纯净性]]。

## 关键特征
- **零工具定义**：注册表仅保存技能名称字符串，不包含参数描述、JSON Schema 或任何工具元信息
- **上下文零污染**：从源头杜绝因预加载工具定义而导致的上下文膨胀，保持意图识别阶段窗口的纯净
- **运行时动态拉取**：工具定义推迟到技能匹配完成后，再按需获取对应的完整 Schema
- **与意图识别解耦**：意图识别模块仅依赖技能名称列表进行路由判断，不受工具细节干扰
- **配合无状态上下文**：适配[[concepts/无状态上下文|无状态上下文]]设计理念，每次调用保持独立性

## 应用
- **智能体意图路由**：在 LLM Agent 系统中，L1 路由器仅读取技能名称列表即可完成意图分类，避免大量工具定义挤占上下文
- **大规模技能管理**：当系统拥有数十甚至上百个技能时，传统预加载方式会导致上下文溢出，而仅含名称的注册表可轻松承载海量技能索引
- **低延迟意图识别**：减小上下文体积可显著降低推理延迟，提升 Agent 响应速度
- **可演化架构**：技能的新增、移除不影响意图识别阶段，便于系统持续迭代
