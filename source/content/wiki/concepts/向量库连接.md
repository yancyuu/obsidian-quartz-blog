# 向量库连接

## 定义
向量库连接是 memory-context 模块的核心组件之一，位于 `vector_store.py` 中。它负责建立和维护与向量数据库的连接，为 Agent 提供语义检索和相似度匹配的能力。与 Redis 历史管理模块共同构成 Agent 的记忆与上下文管理系统，支撑 RAG 等检索增强能力。

## 关键特征
- **语义检索能力**：通过向量嵌入（Embedding）实现基于语义的相似度匹配，而非传统的关键词匹配
- **连接管理**：封装向量数据库的连接建立、维护和释放逻辑，对上层提供统一接口
- **长时记忆支撑**：为 Agent 提供跨会话的知识存储与检索能力，是 Agent 长时记忆的基础设施
- **与历史管理协同**：与 Redis 历史管理模块配合，共同构成完整的记忆与上下文管理系统（memory-context）
- **模块化设计**：作为 memory-context 模块的独立组件，可按需加载，符合 Agent 架构的按需连接原则

## 应用
- **RAG 检索增强生成**：在 Agent 响应用户请求前，从向量库中检索相关知识片段，注入到上下文中以增强回答质量
- **语义搜索**：为 Agent 提供基于语义而非关键词的文档检索能力
- **知识库问答**：将企业文档、FAQ 等知识向量化存储，支持 Agent 在推理时实时检索调用
- **相似度匹配**：在多轮对话中检索与当前意图最相似的历史会话或处理方案
