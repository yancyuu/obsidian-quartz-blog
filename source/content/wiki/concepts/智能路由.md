# 智能路由

## 定义
智能路由（Router）是现代 Agent 系统的核心组件之一，取代了传统 `if-else` 硬编码条件分支，通过概率性匹配的方式将用户意图、任务请求动态分发到最合适的处理路径或工具。它是实现 Agent 架构从"确定性代码逻辑"向"概率性模型决策"转变的关键枢纽。

## 关键特征
- **范式性替代**：取代传统的 `if-else` 确定性逻辑，采用基于模型理解的概率性分发机制。
- **稀疏代码节点**：正如 Karpathy 所描述的"代码变稀疏"的地方，系统在该节点不再依赖密集的硬编码规则，而是让大模型来决策走向。
- **动态适配性**：能够根据输入内容的语义动态选择处理路径，无需为每一种情况预先编写判断逻辑。
- **架构核心位置**：在现代 Agent 架构中，通常与 ToolBox（工具箱）和 Critic（校验组件）协同工作，构成完整的智能体流转闭环。

## 应用
- **Agent 任务分发**：在多工具、多场景的 Agent 系统中，根据用户 Prompt 的意图自动选择调用哪个 API 或子 Agent。
- **客服与对话系统**：识别用户咨询的领域和意图，将对话路由至最匹配的业务处理流程。
- **复杂业务编排**：在自动化工作流中充当大脑，决定下一步应触发的具体业务节点。
