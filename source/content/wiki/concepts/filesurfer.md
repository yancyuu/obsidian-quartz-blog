# FileSurfer

## 定义

FileSurfer 是 Magentic-UI 架构中的文件浏览器智能体，配备 Docker 容器和文件转换工具，能够定位、转换文件并回答相关问题。它在多智能体团队中负责处理文件相关的操作任务，与其他专门化智能体（如 WebSurfer、Coder）形成互补。FileSurfer 通过 Docker 容器实现安全的文件处理环境，体现了多智能体系统中功能分治的设计原则。

## 关键特征

- **Docker 容器隔离**：通过 Docker 容器提供安全的文件处理沙箱环境，确保文件操作的安全性与隔离性
- **文件转换能力**：配备文件转换工具，支持多种文件格式的定位、读取与转换操作
- **专门化职责**：作为多智能体团队中的专门化角色，聚焦于文件浏览与文件相关的问答任务
- **与其他智能体互补**：与 WebSurfer（网页浏览）、Coder（代码编写）等智能体协同工作，形成功能完整的多智能体团队
- **基于 LLM 驱动**：作为 LLM 智能体，能够理解文件内容并回答与文件相关的用户问题

## 应用

- 在多智能体系统中承担文件浏览与检索任务，辅助用户定位目标文件
- 对上传或本地存储的文件进行格式转换，满足下游处理需求
- 基于文件内容回答用户提出的针对性问题，实现文件内容的智能问答
- 在 [[concepts/多智能体协作|多智能体协作]] 场景中，为其他智能体提供文件数据支持
