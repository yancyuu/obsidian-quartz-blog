# 权限物理隔离

## 定义
权限物理隔离是一种 RAG（检索增强生成）系统中的安全策略方法。其核心理念是：**不在 Prompt 层面进行权限控制**（如通过自然语言指令 "if user is manager" 判断身份），而是**在向量数据库的 Metadata（元数据）层面直接实现权限隔离**。系统在执行查询的第一步即通过 Metadata 过滤掉用户无权限访问的文档，从数据层面根本性地杜绝越权访问的风险。

## 关键特征
- **数据层隔离优先**：将权限控制下沉到向量库的 Metadata 层，而非依赖 LLM 的 Prompt 逻辑判断，避免大模型"不听话"导致的安全漏洞。
- **查询前过滤机制**：权限过滤发生在检索（Retrieval）阶段之前，即用户查询的第一步就被 filter 截断，无权限文档根本不会进入候选集。
- **物理级安全**：与 Prompt 级别的"软"权限控制不同，Metadata 过滤是一种"硬"隔离，大模型无法绕过，从根本上消除越权风险。
- **与角色系统解耦**：权限标签独立于业务逻辑维护，通过 Metadata 字段（如部门、角色、密级）管理，便于扩展和审计。

## 应用
- **企业内部知识库**：防止普通员工检索到管理层专属的薪资表、财务报表等敏感文档。
- **零售行业客服系统**：在卤味零售巨头客服 RAG 系统中，通过 Metadata 标签确保店员只能检索到商品信息、操作手册，而无法搜到店长的薪资表或运营数据。
- **多租户 SaaS 平台**：不同租户的数据通过 Metadata 中的租户 ID 进行物理隔离，确保 A 租户永远无法检索到 B 租户的文档。
- **分级保密系统**：对机密文档标注密级标签（如"公开"、"内部"、"机密"），根据用户安全等级在向量库层面过滤检索结果。
