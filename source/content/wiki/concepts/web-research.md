# Web Research

## 定义
Web Research 是一种为 AI Agent 配置的外部搜索 MCP（Model Context Protocol）服务/工具。其核心作用是在 Agent 内部知识不足以解决问题时，提供向外部知识源查询相关框架或错误信息的能力，从而增强 Agent 的问题解决与代码编写能力。

## 关键特征
- **外部知识补充**：当 Agent 依赖内部知识无法解决问题时，充当连接外部信息源的桥梁。
- **问题优先定位**：要求 Agent 在遇到报错或未知问题时，先通过该工具查询并确定问题根因，再进行后续操作（如编写代码）。
- **MCP 协议集成**：作为一种 MCP（Model Context Protocol）服务/工具进行挂载和配置，遵循标准化的协议封装。
- **跨智能体通用**：适用于不同类型的智能体配置（如代码编写 Agent 和代码阅读 Agent）。

## 应用
- **报错排查**：在开发过程中遇到异常或报错时，Agent 自动调用该工具搜索相关框架文档或错误描述，定位问题原因后再生成修复代码。
- **框架学习**：面对不熟悉的框架或 API 时，主动检索最新文档与用法，避免基于过时或错误的内部记忆编写代码。
- **知识增强**：作为 Agent 工具链的标准组件，在系统架构层面确保智能体具备动态获取外部知识的能力，提升闭环业务的处理质量。
