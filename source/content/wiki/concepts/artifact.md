# Artifact

## 定义
Artifact 是 [[concepts/a2a|A2A]] 协议中定义的智能体协作返回结果的概念，指代 Agent 在任务执行过程中产生并流式返回给请求方的消息或工件产物。它支持多模态内容（文本、音频、视频），是 A2A 协议处理长期任务、用户输入等待和交互补充等状态时的核心数据载体。通过 Artifact 机制，A2A 实现了多个智能体协同处理多轮任务时的结果传递和状态同步。

## 关键特征
- **流式返回**：Artifact 支持在任务执行过程中以流式方式逐步返回结果，适配长期运行任务的实时反馈需求
- **多模态支持**：可承载文本、音频、视频等多种模态的内容，满足复杂交互场景
- **状态同步载体**：作为 A2A 协议中多智能体协作的核心数据结构，负责在多个 Agent 之间传递任务产物与中间状态
- **多轮任务适配**：支持在任务执行过程中等待用户输入或进行交互补充，实现灵活的多轮任务处理

## 应用
- **多智能体协同任务**：在多个 Agent 协作完成复杂任务时，通过 Artifact 传递中间结果和最终产物
- **长期运行任务**：对于执行时间较长的任务，通过流式返回 Artifact 实现进度的实时反馈
- **多模态交互场景**：在需要返回文本、语音、视频等多种类型结果的智能体应用中作为统一的数据载体
- **人机协作流程**：在 Agent 需要等待用户补充输入或确认的场景中，通过 Artifact 机制实现状态挂起与恢复
