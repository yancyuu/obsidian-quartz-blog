# 调用与返回数据流

## 定义
调用与返回数据流是 Agent 系统架构中，中控大脑（核心推理引擎）与工具层组件之间的一种双向通信模式。在每个执行步骤中，中控大脑向工具层组件（如 Web Search、Python 解释器等）发起调用请求，工具层组件接收请求并处理后将结果数据返回给中控大脑。这种"调用-返回"的数据流转模式是 Agent 系统实现工具增强的核心机制，贯穿于所有执行步骤之中。

## 关键特征
- **双向通信**：中控大脑与工具层之间存在请求-响应的双向数据通道，而非单向的数据推送
- **步骤化驱动**：数据流以执行步骤为单位，每个步骤包含一次完整的调用与返回周期
- **工具解耦**：工具层组件作为独立的服务单元，通过标准化的调用接口与中控大脑交互
- **贯穿性**：该数据流模式存在于 Agent 运行的全生命周期，是所有执行步骤的基础通信框架
- **结果驱动决策**：返回的数据直接作为中控大脑下一步推理与决策的输入

## 应用
- **Agent 架构设计**：作为系统设计的核心通信范式，指导中控大脑与工具层之间的接口定义和数据协议设计
- **多步骤任务执行**：在需要调用多种工具（如搜索、计算、数据查询）的复合任务中，每一步均通过调用与返回数据流完成信息传递
- **工具增强推理**：中控大脑根据当前推理状态动态选择工具、发起调用，并基于返回结果调整后续执行计划
