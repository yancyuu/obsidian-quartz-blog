# 线程池/进程池

## 定义
线程池和进程池是异步编程中用于处理 CPU 密集任务的标准机制。由于 asyncio 在单线程事件循环中运行，CPU 密集任务会阻塞整个事件循环。通过 `loop.run_in_executor()` 将这类任务分发到线程池或进程池中执行，可以避免阻塞事件循环，从而保持异步程序的并发性能。

## 关键特征
- **解耦计算与事件循环**：将 CPU 密集型任务从事件循环所在的主线程中移出，防止事件循环被长时间占用
- **统一调度接口**：通过 `loop.run_in_executor()` 提供统一的 API，可透明地将同步函数转为可 await 的协程对象
- **线程池与进程池的选择**：线程池适用于 I/O 间穿插的轻量计算（受 [[concepts/gil|GIL]] 限制）；进程池适用于真正需要利用多核的并行计算
- **非侵入式集成**：现有同步代码无需大规模重构，只需包装即可融入异步架构

## 应用
- **图像/视频处理**：在异步 Web 服务中对上传的图片进行压缩、裁剪等 CPU 密集操作
- **数据序列化与加密**：如 JSON 大规模序列化、加密解密等耗时计算，分发到线程/进程池执行
- **机器学习推理**：在异步 Agent 中调用本地模型推理时，将推理任务交给进程池以避免阻塞
- **混合型应用服务**：在同时处理大量 I/O 请求和部分计算任务的场景下，兼顾高并发与计算吞吐
