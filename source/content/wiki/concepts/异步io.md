# 异步IO

## 定义
异步 IO 是一种 IO 处理模型，程序发起 IO 操作后不需要等待其完成，而是立即转去执行其他任务。当底层 IO 操作完成后，通过事件通知机制告知程序处理结果。与同步 IO 相比，它避免了 CPU 在等待 IO 期间的空转。其本质可概括为单线程、事件循环和 IO 多路复用的结合体。

## 关键特征
- **非阻塞**：发起 IO 操作后不阻塞等待，立即切换执行其他就绪任务
- **事件驱动**：通过事件通知机制在 IO 完成后回调处理结果
- **CPU 高效利用**：IO 等待期间不浪费 CPU 资源，交由事件循环调度其他就绪协程
- **单线程并发**：结合事件循环与协程，在单线程内实现高并发处理

## 应用
- 高并发网络服务器（如 Web 服务器、API 网关）
- 实时数据处理与流式 IO 场景
- Python `asyncio` 等异步编程框架的底层支撑
- 数据库/缓存等高延迟 IO 操作的并发优化
