## Description
意图路由的本质是在系统最前端设置一道"分流闸门"，根据用户意图将请求精确导向对应的处理路径。在 RAG 系统中，它通过分类器判断查询意图并限定检索范围，从物理层面杜绝跨域召回，彻底消除「问工资搜出促销」这类因语义相似但领域不同而产生的幻觉问题，相比事后 rerank 在准确性和速度上均有显著优势。在 Agent 应用架构中，意图路由作为 orchestration 编排模块的核心组件（通常实现于 `router.py` 中），负责接收用户请求并将其智能分发到对应的 Agent 或处理流程。它与 [[entities/langgraph|LangGraph]] 封装的状态图协同工作，实现基于用户意图的精确请求路由和任务分发，是整个系统编排能力的核心。
