# RORO模式

## 定义
RORO（Receive Object, Return Object）模式是一种软件工程设计方法，要求函数以对象作为输入参数并返回对象作为输出，而不是使用多个分散的基本类型参数。该模式与 Pydantic 模型的使用深度结合，有助于保持函数签名的一致性和可扩展性，是构建模块化、可维护代码的架构指导原则。

## 关键特征
- **对象输入输出**：函数参数和返回值均使用对象封装，而非多个分散的基本类型
- **签名一致性**：统一采用对象作为函数边界，降低参数数量带来的复杂度
- **可扩展性**：通过在对象中新增字段实现功能扩展，无需修改函数签名，避免破坏性变更
- **与类型系统结合**：深度结合 [[concepts/类型提示|类型提示]] 和 Pydantic 模型，提供编译期与运行时的类型安全保障
- **声明式风格**：符合 [[concepts/函数式编程|函数式编程]] 的声明式理念，关注数据流转而非过程控制

## 应用
- **Python 应用开发**：作为核心设计规范，指导项目中的函数与接口设计
- **AI Agent 工程**：在 Agent 架构中统一数据流转格式，使模块间的通信更加规范
- **API 接口设计**：后端服务接口采用对象作为请求与响应载体，提高接口的可维护性
- **Pydantic 数据建模**：结合数据验证模型，实现参数校验与业务逻辑的解耦
