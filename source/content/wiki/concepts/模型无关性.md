# 模型无关性

## 定义
模型无关性是[[concepts/可逃逸架构|可逃逸架构]]的第三大设计原则，要求代码中严禁出现具体模型名称（如 gpt-4、claude-3.5）和硬编码 API Key。所有大模型调用必须通过 OneAPI、LiteLLM 等网关层统一路由，使系统对底层 LLM 提供商保持透明，可以随时响应模型市场的变化。

## 关键特征
- **禁止硬编码**：代码中严禁出现 gpt-4、claude-3.5 等具体模型名称，严禁硬编码 API Key
- **网关层调用**：所有大模型请求必须通过 OneAPI / LiteLLM 等网关层统一转发，业务代码不直接对接厂商 SDK
- **配置驱动切换**：切换模型提供商只需修改一行配置（Config），而非修改业务代码
- **供应商透明**：系统对底层 LLM 提供商完全透明，不绑定任何特定厂商

## 应用
- **模型迁移**：当需要从国外模型（如 GPT-4、Claude）切换到国产模型（如 DeepSeek）时，仅需调整网关配置，无需改动业务代码
- **多模型路由**：通过[[concepts/模型路由|模型路由]]网关层，根据任务类型、成本、延迟等策略动态选择最优模型
- **成本优化**：在模型市场价格波动时，快速切换到性价比更高的模型，降低整体推理成本
- **合规与数据安全**：在需要满足数据出境合规要求时，可迅速将流量切换至国产模型供应商
