# 自回归生成

## 定义
自回归生成是大语言模型（LLM）逐个 token 生成文本的核心机制。在每生成一个新 token 时，模型通过注意力机制对所有历史 token 进行计算。若不做缓存，计算复杂度会随序列长度呈 O(n²) 级别增长，是 KV Cache 技术存在的根本原因。

## 关键特征
- **逐步生成**：每次只生成一个 token，新 token 依赖于之前已生成的所有 token。
- **注意力全量计算**：每生成一个新 token，注意力机制都要对前面所有 token 进行计算。
- **计算复杂度高**：若不引入缓存机制，第 t 步需将前 t-1 个 token 全部重算一遍，整体复杂度为 O(n²)，速度极慢。
- **依赖缓存优化**：通过 KV Cache 等技术，可将每步从 O(t) 的全量重算降为 O(1) 的增量计算，实现实时生成。

## 应用
- 大语言模型的文本生成（如对话回复、代码补全、文章续写）。
- 推理加速与缓存优化系统（如 KV Cache、Prompt Caching）的设计与实现。
