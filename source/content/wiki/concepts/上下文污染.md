# 上下文污染

## 定义
上下文污染是指在 Agent 运行时，上下文窗口被过多不相关的工具定义和无关信息占据，导致有效信息比例下降，进而影响大模型推理质量和响应速度的现象。在可逃逸架构中，这一问题通过技能注册表仅存储技能名、运行时按需加载工具定义的机制来加以解决，确保传递给 L1 Router 的意图信号保持纯净。

## 关键特征
- **上下文窗口占用**：不相关的工具定义占据有限的上下文窗口空间，挤压有效推理信息的容量。
- **推理质量下降**：大量冗余信息干扰模型注意力分配，导致意图识别精度降低、推理质量受损。
- **响应速度变慢**：过长的上下文增加模型处理延迟，影响 Agent 的实时响应能力。
- **意图信号失真**：无关上下文与用户真实意图混合，导致传递给路由层的信号不再纯净。
- **可通过架构设计规避**：采用技能注册表分离与运行时按需加载机制，从源头消除污染。

## 应用
- **Agent 架构设计**：在设计 L1 Router 路由层时，通过技能注册表仅暴露技能名称而非完整工具定义，避免上下文污染。
- **运行时工具加载**：在 L2 Worker 实际执行阶段才按需加载所需工具定义，保持路由阶段的上下文纯净。
- **上下文窗口管理**：作为评估 Agent 架构质量的核心指标，用于判断系统是否能有效管理上下文资源。
- **企业级 Agent 优化**：在多技能、多工具的复杂企业场景中，通过规避上下文污染来保障系统在高并发下的推理效率。
