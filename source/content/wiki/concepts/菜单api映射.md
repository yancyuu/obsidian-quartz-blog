# 菜单API映射

## 定义
菜单API映射是权限计算逻辑中的关键步骤，用于将抽象的菜单权限转化为具体的API接口权限。在 RBAC 权限模型中，权限计算遵循"角色聚合 → 权限提取 → 菜单映射 → API生成"四步流程，菜单API映射是其中的第三步和第四步。通过这种映射机制，系统可以将前端可见的菜单项与后端的API接口关联起来，实现用户界面权限和接口访问权限的统一管控。

## 关键特征
- **四步流程的核心环节**：菜单映射（第三步）将权限映射到关联的菜单，API 生成（第四步）将菜单映射到关联的 API，生成最终的权限列表
- **前后端权限统一**：将前端可见的菜单项与后端 API 接口关联，确保即使前端菜单被隐藏，后端 API 依然受到同等程度的权限保护
- **链式关联关系**：通过"用户 → 用户组 → 角色 → 权限 → 菜单 → API"的关联关系最终获取权限 API
- **权限保护一致性**：无论用户界面是否展示某菜单项，对应的 API 接口始终受到完整的权限校验

## 应用
- **网关层统一鉴权**：在 API 网关中基于菜单映射结果进行统一的接口权限校验，避免各微服务重复实现鉴权逻辑
- **前端动态菜单渲染**：根据用户角色对应的菜单权限，动态生成前端导航菜单，同时确保后端接口权限与前端展示权限保持同步
- **接口安全防护**：防止攻击者绕过前端界面限制直接调用后端 API，保障所有接口均经过完整的权限链路校验
