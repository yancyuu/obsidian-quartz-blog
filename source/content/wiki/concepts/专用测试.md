# 专用测试

## 定义
专用测试是 Agent 架构中每个业务 Agent 模块内包含的独立测试目录（`tests`）。每个业务代理（如 `coding_agent`、`research_agent`）都拥有自己的独立测试套件，用于验证该 Agent 的核心逻辑、工具绑定和 Prompt 效果。这种设计确保了每个 Agent 模块的质量可独立验证，支持持续集成和自动化测试流程。

## 关键特征
- **模块级独立**：每个业务 Agent 拥有独立的 `tests` 目录，与 Agent 的其他代码（核心逻辑、工具绑定、Prompt 等）共同封装在同一模块内。
- **聚焦验证核心能力**：测试重点覆盖该 Agent 的核心逻辑、工具绑定正确性以及专用 Prompt 的实际效果。
- **可独立运行**：各 Agent 的测试套件互不干扰，支持单独执行和独立验证模块质量。
- **支持持续集成**：为 CI/CD 流程提供基础，确保每次代码变更都能自动触发对应模块的测试。

## 应用
- **模块化开发质量保障**：在多 Agent 系统中，开发人员可针对单个 Agent（如 `coding_agent`）独立编写和运行测试，快速发现回归问题。
- **持续集成流水线**：将各 Agent 的专用测试集成到 CI 流水线中，实现代码提交后的自动化质量门禁。
- **Prompt 迭代验证**：当修改 Agent 的专用 Prompt 或工具绑定时，通过专用测试快速评估改动对 Agent 行为的影响。
