# 延迟加载

## 定义
延迟加载（Lazy Loading）是一种性能优化技术，其核心思想是将数据的加载操作推迟到真正需要使用该数据时才执行，而非在程序启动或初始化阶段一次性全部加载。该技术广泛应用于处理大型数据集和大量 API 响应场景，通过减少不必要的初始加载开销来提升系统响应速度和资源利用率。

## 关键特征
- **按需加载**：仅在数据被实际访问时触发加载逻辑，避免提前加载无用数据造成的资源浪费。
- **减少初始开销**：显著降低应用启动时的 I/O 压力和内存占用，缩短首屏或首次响应时间。
- **与异步函数协同**：通常与异步非阻塞 I/O 配合使用，在等待数据加载期间不阻塞主线程或事件循环。
- **与缓存策略互补**：常与 Redis 等缓存机制结合使用，首次延迟加载后将结果缓存，后续请求直接从缓存读取。

## 应用
- **大型数据集处理**：对包含大量记录的数据集采用分页或分块延迟加载，避免一次性将全部数据载入内存。
- **API 响应优化**：面对大量 API 响应数据时，按需请求所需字段或分批获取，降低网络传输和序列化开销。
- **I/O 绑定任务优化**：在文件读取、数据库查询、远程调用等 I/O 密集型场景中，通过异步函数配合延迟加载提升并发性能。
- **前端资源管理**：图片、组件、模块等资源的按需加载，提升页面初始渲染速度。
