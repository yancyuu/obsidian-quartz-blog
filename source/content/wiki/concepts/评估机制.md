# 评估机制

## 定义
评估机制是 Agent 工程的核心主干之一，而非 QA（质量保证）的附属品。它强调系统的可持续改进优先于一次性完美，倡导尽早建立可复用的失败检测与错误归因流程，以半自动化的方式持续发现和定位 Agent 运行中的问题。

## 关键特征
- **工程主干定位**：评估机制不是 QA 的附属品，而是 Agent 工程体系的核心主干之一。
- **可改进优于完美**：系统可持续改进比追求一次性完美更重要，建议尽早上线可复用的"失败检测器"，即使初期只覆盖少量样本。
- **错误归因能力**：对每个 Agent 的失败步骤打标签、记录上下文，形成系统化的错误归因机制。
- **可持续优先**：早期就搭建"可持续评估机制"，哪怕是半自动脚本，也优于全靠人工肉眼检查。

## 应用
- **Agent 上线前验证**：在 Agent 开发早期搭建半自动化的评估脚本，替代纯人工检查，快速发现问题。
- **失败步骤标注**：针对 Agent 执行流程中的每个失败步骤进行标签化记录，保留上下文以供后续分析。
- **错误归因与迭代**：通过积累的失败标签和上下文记录，追溯 Agent 错误根因，指导后续优化迭代。
