# AgentCard

## 定义
AgentCard 是 [[concepts/a2a|a2a]]（Agent-to-Agent）协议中用于标准化描述智能体能力的规范。它定义了智能体如何声明自身的能力、接口和属性，使得其他智能体可以在网络中发现并评估是否需要与之协作。AgentCard 被视为未来"Agent操作系统"的核心基础构件之一。

## 关键特征
- **标准化描述**：以结构化的方式声明智能体的能力边界、支持的接口和属性元数据。
- **服务发现机制**：充当智能体间的"名片"，使得其他智能体能够自动发现并解析其提供的服务。
- **协作评估依据**：其他智能体可基于 AgentCard 中声明的信息，判断是否需要与该智能体建立协作关系。
- **协议核心组件**：与任务分发（send/sendSubscribe）和 Artifact 流式返回机制共同构成多智能体协作的完整通信链路。
- **基于标准Web技术**：在 A2A 协议框架下，通常基于 HTTP + SSE + JSON-RPC 等标准 Web 技术进行传输和解析。

## 应用
- **多智能体网络发现**：在异构多智能体系统中，智能体通过广播或注册 AgentCard 来声明自身服务，供路由和调度组件（如 [[concepts/planner|planner]]）检索和匹配。
- **动态任务委派**：任务发起方解析候选智能体的 AgentCard，评估其能力是否匹配当前需求，从而实现任务的精准分发。
- **Agent生态系统集成**：在构建大规模可演化的智能体系统架构时，作为标准的注册与发现协议，支撑智能体的即插即用。
