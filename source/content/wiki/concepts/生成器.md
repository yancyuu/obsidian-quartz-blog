# 生成器

## 定义
生成器（generator）是 Python 中一种特殊的函数，它使用 `yield` 关键字来暂停执行并产出值，后续可以从暂停处恢复执行。生成器是 Python 协程底层实现的基础——协程本质上就是基于生成器（yield）的状态机。通过 yield 的暂停/恢复机制，协程能够在 `await` 时交还控制权给事件循环，并在 IO 就绪后恢复执行。生成器是 Python 异步编程模型的核心基础设施。

## 关键特征
- **暂停与恢复**：通过 `yield` 关键字暂停函数执行并产出一个值，下次调用时从上次暂停的位置继续执行。
- **状态保持**：生成器在暂停期间保持其局部变量和执行上下文的状态，无需额外存储开销。
- **惰性求值**：值按需生成，而非一次性全部计算完毕，适合处理大数据流或无限序列。
- **协程的底层基础**：Python 协程（`async def`）的底层实现基于生成器的状态机机制，通过 yield 实现 IO 等待时的控制权切换。

## 应用
- **异步编程基础设施**：作为协程的底层实现机制，支撑 Python 的 `asyncio` 异步 IO 模型，使单线程下的高并发成为可能。
- **数据流处理**：逐项产出数据，避免一次性加载全部数据到内存，常用于读取大文件、数据库分页查询等场景。
- **管道与流水线**：将多个生成器串联，构建数据处理管道，实现流式的数据转换与过滤。
- **无限序列生成**：利用惰性求值特性，可以表示如斐波那契数列等数学上的无限序列。
