# 协同规划

## 定义
协同规划是 [[entities/magentic-ui|magentic-ui]] 的核心功能之一，指当用户指定任务后，系统在开始执行前创建一个清晰的逐步计划，用户可以接受、重新创建或通过编辑界面修改计划步骤。这种方法确保用户始终是任务的主导者而非被动接受者，体现了以人为中心的设计理念。

## 关键特征
- **先规划后执行**：Agent 在执行任何操作之前，先描述清晰的逐步行动计划（如查什么数据、如何排序等），用户确认或调整后才执行。
- **用户主导**：用户明确决定 Agent 的行为，而非被动接受 Agent 的自动化结果。
- **可编辑性**：用户可以通过编辑界面对计划步骤进行修改或重新创建，实现灵活的交互。
- **透明可控**：计划过程对用户完全透明，增强用户对 Agent 行为的信任与掌控感。
- **以人为中心**：设计理念强调人机协同中人的主导地位，Agent 作为辅助工具而非完全自治的执行者。

## 应用
- **数据分析任务**：Agent 先给出执行计划（如先查询哪些数据源、如何过滤和排序），用户确认后再自动执行分析。
- **信息检索与处理**：在复杂检索任务中，Agent 先描述检索策略和步骤，用户审阅后执行。
- **自动化工作流**：在多步骤的自动化场景中，用户可以逐步审阅和修改 Agent 生成的执行计划，确保流程符合预期。
