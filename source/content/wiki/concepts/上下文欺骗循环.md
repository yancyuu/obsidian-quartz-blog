# 上下文欺骗循环

## 定义
上下文欺骗循环是用于描述当前 AI Agent 在处理复杂任务时，因上下文窗口限制而陷入的一种系统性恶性循环现象。该概念揭示了 Agent 厂商在宣传中刻意回避的系统本质缺陷：尽管系统看似拥有强大的技能调用能力，但在实际复杂场景中，Agent 会在技能频繁切换、记忆丢失和性能损耗之间反复挣扎，导致任务执行效率和质量急剧下降。

## 关键特征
- **抖动（Thrashing）**：当任务复杂度提升时，Agent 被迫在不同 Skills 之间频繁切换，不断加载和卸载技能模块，类似于操作系统中的内存抖动现象。
- **逻辑断层**：每次上下文"换页"都会导致 Agent 丢失部分短期记忆，造成细节遗忘和推理链条断裂，使任务执行的连贯性遭到破坏。
- **延迟叠加**：每一次文件读取和技能加载都涉及昂贵的 I/O 操作和 Token 生成，多次叠加后导致显著的响应延迟。
- **隐蔽性**：这一循环在日常演示中难以察觉，但在真实复杂任务中会暴露无遗，厂商通常不会在发布会等公开场合展示此缺陷。

## 应用
该概念主要用于：
- **Agent 系统架构诊断**：帮助工程师识别和定位 Agent 在复杂任务中性能退化的根本原因。
- **系统设计评估**：为评估不同 Agent 框架的上下文管理能力提供分析框架。
- **技术选型参考**：帮助团队在选择 Agent 方案时，理性评估其在真实业务场景中的表现上限。
