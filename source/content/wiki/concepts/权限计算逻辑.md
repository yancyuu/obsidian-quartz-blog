## Description
权限计算逻辑支持两种关联关系路径：一种是"用户→用户组→角色→权限→菜单→API"，另一种是"用户→角色→权限→菜单→API"，系统根据实际关联关系获取用户相关权限信息。该逻辑的第一步是角色聚合，即将用户直接关联的角色与用户组关联的角色取并集，形成有效角色集合。这种设计允许系统通过用户组实现批量权限管理，减少逐个用户配置角色的维护成本。后续基于聚合后的角色集合依次完成权限提取、菜单映射和 API 生成，最终输出完整的权限列表。该列表直接作为 API 网关层鉴权的判断依据，同时也可为前端菜单渲染提供数据支持。
