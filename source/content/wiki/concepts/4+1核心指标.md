# 4+1核心指标

## 定义
"4+1"核心指标是作者为 Agent 上线运营定义的一套量化评估标准，包含四个核心指标加一个用户行为指标：成功率（任务完成率）、P95延时（响应速度）、CPT成本/任务（单次任务成本）、误导率 Hallucination（幻觉率）、以及用户步骤 User Steps（用户完成任务所需的交互轮数）。这五个指标构成了 Agent 看板的最简化版本，用于持续监控 Agent 的健康状况和优化方向。

## 关键特征
- **精简看板**：作者建议看板只放成功率、P95、CPT、误导率这四个核心指标，避免信息过载，确保团队聚焦关键问题。
- **用户视角补充**：用户步骤（User Steps）作为第"1"个补充指标，从用户行为角度衡量任务完成所需的交互轮数，反映交互效率。
- **自动化运维**：当核心指标破线（如成功率骤降、误导率飙升）时，可自动触发灰度回滚机制，保障线上稳定性。
- **全维度覆盖**：覆盖了质量（成功率、误导率）、性能（P95延时）、成本（CPT）和体验（用户步骤）四大维度。

## 应用
- **Agent 上线运营监控**：作为 Agent 看板的标准配置，持续跟踪线上运行健康度。
- **灰度发布与自动回滚**：将核心指标设定阈值，一旦破线即触发自动化灰度回滚流程，降低故障影响。
- **团队对齐与沟通**：以最简化的指标集合让产品、研发、运营团队快速对齐当前 Agent 的核心瓶颈和优化优先级。
