# 阶段机

## 定义
阶段机是一种用于解决 Agent 多轮对话失忆问题的流程控制方法，其本质是一种有限状态机。通过严格限制每个节点可用的工具和流程走向——包括规定前置条件、可重试次数和回退条件——阶段机能够精确管控 Agent 在任务流程中的每一步行为，防止 LLM 在上下文压力下出现"人格分裂"或行为失控。

## 关键特征
- **有限状态机本质**：将复杂业务流程拆分为离散的、可控的阶段节点，每个节点有明确的状态边界。
- **工具与流程限制**：在每个阶段仅暴露该阶段所需的工具集，避免 Agent 因可选工具过多而产生决策混乱。
- **条件驱动**：通过前置条件、可重试次数、回退条件等机制严格约束状态转移逻辑。
- **分而治之**：用流程拆分替代对记忆压缩等技术的依赖，降低工程复杂度。
- **高性价比**：作者认为相比投入大量精力研究记忆压缩等技术，阶段机这种分而治之的方案最具性价比。

## 应用
- **客服 Agent 流程管控**：将客服对话拆分为"意图识别 → 信息收集 → 方案提供 → 满意度确认"等阶段，每个阶段限制可用工具和允许的下一步操作，防止 Agent 跳过必要步骤或陷入循环。
- **复杂任务编排**：与显式节点图配合使用，将多步骤业务流程拆解为可控的阶段链，确保 Agent 按预定路径执行。
- **Agent 行为一致性保障**：在长对话或多轮交互场景下，通过阶段约束防止 LLM 因上下文窗口压力而产生不一致的行为表现。
