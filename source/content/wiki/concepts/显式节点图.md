# 显式节点图

## 定义
显式节点图是解决 Agent 多轮对话后"失忆"问题的核心方法。其核心思想是将复杂的业务流程（如询价 → 确认 → 支付）画成结构化的任务图，严格控制每一步的执行逻辑，而非完全依赖 LLM 的隐式记忆来维持流程连贯性。

## 关键特征
- **结构化流程控制**：将任务流程显式地画成图，严格控制每个节点能做什么。
- **权限与边界限制**：配合阶段机使用，限制每个节点可用的工具和流程走向。
- **条件管理**：明确规定每个节点的前置条件、可重试条件和回退条件。
- **分而治之**：通过拆分复杂流程降低单次推理的认知负荷，性价比远高于记忆压缩等技术。

## 应用
- **多轮对话 Agent**：解决上下文窗口压力大时出现的"人格分裂"问题，确保流程不跑偏。
- **复杂业务流程编排**：适用于需要严格步骤控制的场景（如电商询价、支付确认等），避免 LLM 因记忆过载而遗漏关键步骤。
- **Agent 工程化治理**：作为 Agent 编排框架的基础设计模式，提升系统可靠性和可维护性。
