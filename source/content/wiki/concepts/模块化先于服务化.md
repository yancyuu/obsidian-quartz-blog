# 模块化先于服务化

## 定义
模块化先于服务化是智能体（Agent）系统工程实践中的一项核心架构原则。该原则主张在构建 Agent 系统时，应优先将每个 Agent 封装为模块化的工程函数组件，使其像函数一样可以独立局部调试、灵活组合复用、调用成本可控。待系统运行后，再针对真正高流量、高频协作的 Agent 进行服务化部署，避免过早引入分布式复杂度。

## 关键特征
- **函数化封装**：每个 Agent 被视为一个函数级别的工程组件，具备明确输入输出接口，支持局部调试与单元级验证
- **统一调度管理**：通过统一调度器（Scheduler）管理各 Agent 之间的调用关系，而非一开始就采用点对点的服务调用
- **渐进式服务化**：仅对流量大、协作频繁的热点 Agent 进行服务化部署，其余保留本地函数形态，降低系统复杂度
- **MCP 协议衔接**：热点 Agent 服务化后注册为 MCP 客户端，热点工具注册为 MCP 服务，实现跨进程/跨服务的标准化通信
- **成本可控**：模块化阶段以最低成本验证逻辑与流程，避免过早服务化带来的网络开销、部署成本和运维负担

## 应用
- **智能体系统从原型到生产的演进**：在原型阶段以本地模块快速迭代验证，确认协作模式后再按需服务化
- **多 Agent 协同场景**：对高频协作的 Agent（如订餐 Agent）进行服务化部署，低频 Agent 保持本地调用
- **工具治理与复用**：将热点工具统一注册为 MCP 服务，便于跨系统、跨团队共享与治理
