# 应用入口与配置

## 定义
应用入口与配置是 Agent 系统的最外层基础设施，包含 API 框架入口（FastAPI 或 Sanic）、配置文件（settings.py 和 .env 环境变量）以及运维脚本。这一层负责应用的启动、环境配置管理和运维操作支持，是整个系统正常运行的基础。

## 关键特征
- **多框架支持**：兼容 FastAPI 和 Sanic 两种主流异步 API 框架作为应用入口
- **配置分层管理**：通过 settings.py（代码级配置）和 .env（环境变量级配置）实现配置的分层与隔离
- **运维脚本集成**：内置 scripts 运维脚本目录，支持部署、数据迁移等运维操作
- **基础设施定位**：作为系统的最外层，为内层核心业务逻辑（如 Agent 中控、技能执行等）提供运行环境

## 应用
- Agent 应用服务的启动与对外接口暴露
- 开发/测试/生产等多环境配置切换与管理
- 数据库连接、API 密钥等敏感配置的环境变量注入
- CI/CD 流程中的自动化部署与运维脚本调用
