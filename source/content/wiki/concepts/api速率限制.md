# API速率限制

## 定义
API 速率限制（Rate Limit）是 LLM 服务提供商（如 OpenAI）对单位时间内 API 调用次数施加的配额约束机制。当 Agent 在面对模糊意图或脏数据时陷入死循环并引发无限递归调用，不仅会造成 Token 消耗的财务亏损，更可能直接击穿 API 的速率限制，导致服务中断。

## 关键特征
- **配额约束性**：对单位时间内的请求次数或 Token 消耗量设定上限，超出即被拒绝服务
- **级联风险性**：Agent 的无限递归调用可在短时间内产生海量请求，迅速耗尽配额
- **财务关联性**：速率限制击穿往往伴随严重的 Token 消耗与财务亏损
- **不可预测性**：当 Agent 面对脏数据或模糊意图进行自我纠正时，可能无意识地触发无限循环，使速率限制在毫无预警的情况下被击穿

## 应用
- **企业级 Agent 架构设计**：在高并发场景下引入 [[concepts/有限状态机]] 等 Agent 行动约束机制，防止 Agent 陷入无限递归调用
- **成本管理与监控**：作为 [[concepts/成本管理]] 的关键指标，对 API 调用进行实时监控与熔断
- **系统防护策略**：在 Agent 工程实践中，通过前置数据校验和意图澄清机制，从源头避免触发死循环
