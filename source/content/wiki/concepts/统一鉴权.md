# 统一鉴权

## 定义
统一鉴权是一种核心架构方法，指通过 API 网关对所有前端请求进行集中的身份验证和权限校验。该方法将鉴权逻辑从各个业务系统中抽离，统一前置到网关层执行，依托独立的 IAM（身份与访问管理）系统提供权限数据支撑，根据鉴权结果决定是否将请求转发至业务系统。

## 关键特征
- **集中化处理**：所有 API 请求的鉴权逻辑统一在网关层执行，而非分散在各业务系统中
- **权限数据外置**：依托独立的 IAM 系统完成权限校验，实现权限数据与业务逻辑的解耦
- **前置拦截**：请求在到达业务系统之前即完成身份验证与权限判断，无权限请求直接被拦截
- **Token 解析机制**：前端发起携带用户 Token 的 API 请求，由网关负责解析处理
- **安全策略一致性**：所有接入系统共享统一的安全策略，便于集中管控

## 应用
- **企业级微服务架构**：在多业务系统环境中，通过网关统一拦截和校验所有入站 API 请求
- **访问控制与审计**：集中化的鉴权节点便于实施统一的访问控制策略和安全审计
- **降低业务系统复杂度**：各业务系统无需各自实现鉴权模块，专注核心业务逻辑
- **安全防护前置**：在请求进入内部网络之前完成身份验证，形成第一道安全屏障
