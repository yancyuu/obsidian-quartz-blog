# 幂等键

## 定义
幂等键是解决 Agent 工具调用重复执行问题的核心机制。在交易类场景（如订餐、支付、购票）中尤为关键，通过为每次操作分配唯一标识符，确保即使因网络抖动等原因导致 Agent 重试，也不会重复创建订单或重复扣费。

## 关键特征
- **唯一标识**：每次工具调用携带唯一 ID（如会话任务 ID），系统据此判断请求是否为重复提交
- **防重复执行**：即使 Agent 在网络异常后重试，同一幂等键的请求只会被处理一次
- **事务安全基础**：是 Agent 工程化落地中保障事务安全性的基础手段，防止资源污染和用户利益受损
- **配合原子服务**：需与订单原子化和补偿链配合使用，将价格计算和库存校验前置为原子服务并输出快照，确保购物车数据一致性

## 应用
- **订餐场景**：防止因 Agent 重试导致重复下单或重复扣费
- **支付场景**：保障支付操作的幂等性，避免多次扣款
- **购票场景**：确保库存校验和出票操作的原子性与一致性
- **Agent 工程化**：作为工具调用的安全防护机制，约束 Agent 的事务边界，防止"越权"在一次对话中完成所有事务
