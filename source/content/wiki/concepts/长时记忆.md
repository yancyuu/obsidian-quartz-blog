## Description
长时记忆是 Agent 系统实现状态持久化和持续学习的核心基础。与 Copilot 偏重短期上下文处理不同，具备长时记忆的 Agent 可以在较长的时间维度内保存信息，支持跨会话引用过去的交互记录与决策结果。在实际架构中，长时记忆通常依赖向量数据库（VectorDB）作为底层技术组件，通过向量化存储和相似度检索来高效获取历史上下文。在中控大脑架构中，系统处理用户指令时会首先检索长期记忆中存储的历史上下文，以保持对话连续性并利用过往经验，这也是 RAG 架构的关键基础设施。这一机制使 Agent 能够在多轮、多日甚至更长的周期中持续推进复杂任务，不受单次会话的上下文窗口限制。
