# 工具绑定

## 定义
工具绑定是每个 Agent 目录下的 `tools.py` 文件所负责的功能，用于将该 Agent 所需的具体工具注册和绑定到 Agent 实例上。通过工具绑定机制，每个 Agent 可以声明自己需要使用的工具集合，而工具的具体实现则在通用 `modules` 模块中定义。这种设计实现了工具定义与工具使用的分离，符合可逃逸设计原则。

## 关键特征
- **声明式绑定**：每个 Agent 在自身的 `tools.py` 中声明所需的工具集合，而非硬编码在业务逻辑中。
- **定义与使用分离**：工具的具体实现在通用 `modules` 模块中统一维护，`tools.py` 仅负责引用和注册。
- **按 Agent 隔离**：不同 Agent 拥有独立的工具绑定配置，互不干扰，支持细粒度的工具治理。
- **符合可逃逸设计**：工具绑定层可被替换或重写，而不影响 Agent 的核心业务逻辑。

## 应用
- 在多 Agent 系统中，每个业务 Agent（如客服 Agent、分析 Agent）通过各自的 `tools.py` 绑定不同的工具集，实现差异化的能力配置。
- 在工具升级或替换场景中，只需修改 `tools.py` 中的绑定关系，无需改动 Agent 的核心代码。
- 在团队协作开发中，工具实现由公共模块统一维护，各 Agent 开发者只需关注绑定声明，降低耦合度。
