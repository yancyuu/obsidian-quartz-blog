# async/await

## 定义
async/await 是 Python 3.5（PEP 492）引入的异步编程语法标准，用于定义协程函数和暂停协程执行。`async def` 定义协程函数，调用时返回协程对象但不立即执行；`await` 暂停当前协程并将控制权交还事件循环，等待结果就绪后恢复执行。

## 关键特征
- **协程定义**：`async def` 关键字用于定义协程函数，调用后返回协程对象而非立即执行
- **暂停与恢复**：`await` 关键字暂停当前协程，把控制权交还事件循环，等结果就绪后恢复
- **传染性**：一旦使用异步，调用链上的相关代码也需要异步化，编程模型上与普通同步代码有显著区别
- **事件循环驱动**：依赖事件循环调度执行，现代 Python 推荐使用 `asyncio.run()` 作为入口

## 应用
- 高并发网络服务的异步 I/O 处理（如 Web 服务器、API 网关）
- 数据库连接池与缓存访问的异步封装
- 爬虫与实时数据流的并发抓取
- 需要高效管理大量 I/O 密集型任务的场景
