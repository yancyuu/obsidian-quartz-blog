# 无状态上下文

## 定义
无状态上下文是可逃逸架构的核心理念之一，强调 Agent 运行时不持有持久的工具定义和会话状态，而是在运行时动态加载所需工具。这种设计通过按需加载策略来管理上下文，避免将所有工具定义一次性加载到上下文窗口中，从而有效缓解上下文窗口压力，防止上下文污染，是整个可逃逸架构能够实现的关键前提。

## 关键特征
- **运行时动态加载**：Agent 运行时不预载全部工具定义，仅在实际需要时按需动态加载
- **上下文窗口减压**：避免大量工具定义一次性灌入上下文窗口，有效缓解上下文窗口压力
- **防止上下文污染**：通过按需建立连接策略，保持意图纯粹性，避免无关信息污染上下文
- **无持久会话状态**：运行时不持有持久的会话状态，降低系统耦合度
- **架构基础性**：是可逃逸架构及路由架构与按需加载能够实现的前提条件

## 应用
- **可逃逸架构实现**：作为可逃逸架构的基础支撑，确保系统具备灵活替换与演化的能力
- **路由架构调度**：在 L1 Router -> L2 Worker 架构中，Worker 仅在接收到路由任务后才动态加载对应工具
- **多智能体协同**：在多 Agent 协作场景中，各 Agent 按需加载自身所需工具集，避免全局上下文膨胀
- **企业级 Agent 部署**：在工具数量庞大的企业级场景中，通过无状态上下文管理大规模工具集
