# 函数式编程

## 定义
一种编程范式，将计算视为数学函数的求值，强调使用纯函数、避免可变状态和副作用。在本文档的规范中，函数式编程被确立为 Python Web 开发的核心哲学基础，要求 Agent 尽可能避免使用类，转而使用纯函数和声明式风格进行代码组织。

## 关键特征
- 尽可能避免使用类，优先采用纯函数进行逻辑封装
- 采用声明式编程风格，关注"做什么"而非"怎么做"
- 优先选择迭代和模块化，避免代码重复（DRY 原则）
- 倡导使用接收对象、返回对象（RORO）模式，保持函数输入输出的一致性
- 函数应尽量保持无副作用，提升可测试性和可维护性

## 应用
- **Sanic 路由定义**：使用函数式方式定义路由处理逻辑，而非基于类的视图
- **工具函数导出**：以纯函数形式封装和导出工具函数，便于模块化调用
- **Agent 编码规范**：作为 Agent 编码规范的哲学基础，贯穿整个代码库的设计与实践
