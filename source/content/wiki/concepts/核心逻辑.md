# 核心逻辑

## 定义
核心逻辑是每个 Agent 的 `agent.py` 文件中实现的主要业务逻辑。它定义了该 Agent 的核心行为模式、决策流程和输出格式，是 Agent 能力的具体体现。核心逻辑通过调用绑定的工具、使用专用 Prompt 和访问记忆系统来完成特定的业务任务，与工具绑定和 Prompt 定义共同构成 Agent 的完整业务闭环。

## 关键特征
- **行为定义**：明确 Agent 的核心行为模式和决策流程，是 Agent 区别于其他组件的关键所在。
- **工具调用**：通过调用已绑定的外部工具或内部函数来执行具体操作，实现能力的扩展。
- **输出规范**：定义 Agent 的输出格式和数据结构，确保下游系统可以正确解析和使用处理结果。
- **业务闭环**：与工具绑定和 Prompt 定义协同工作，共同构成完整的业务处理闭环。
- **文件载体**：以 `agent.py` 文件为载体，遵循标准化的代码结构规范。

## 应用
- 在 Agent 应用开发中，开发者通过编写 `agent.py` 文件来实现特定 Agent 的核心业务逻辑。
- 配合专用 Prompt 和工具绑定，完成如舆情分析、智能客服、内容创作等具体业务场景的任务处理。
- 作为 Agent 架构的核心组件，支持 Agent 的快速开发、测试和迭代部署。
