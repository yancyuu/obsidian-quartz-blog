# 存量改造

## 定义
存量改造（Legacy Modernization）是企业落地 Agent 应用的两条核心路径之一，被业界称为"变革的主战场"。其核心是在企业成熟的核心业务系统（如 ERP、CRM、IAM）中嵌入 AI Agent 能力，以激活存量系统的智能化潜力，而非构建全新的独立系统。该路径虽价值释放周期短，但常面临老旧系统缺乏接口的"黑盒"挑战，通常需要结合双模执行架构（API + RPA）进行非侵入式集成。

## 关键特征
- **主战场定位**：是绝大多数企业在 AI 转型中优先选择的路径。
- **价值释放快**：通过在现有核心业务系统中直接引入 Agent，能够迅速产生业务价值。
- **非侵入式集成**：针对老旧系统，采用 RPA（机器人流程自动化）通道进行表面层级的操作交互，避免大规模重构。
- **双模协同**：结合 API 通道（针对现代化系统）与 RPA 通道（针对老旧黑盒系统），实现系统全面覆盖。

## 应用
- **ERP 系统智能化升级**：在传统的企业资源规划系统中嵌入 Agent，实现自动化的库存查询、财务报表生成或智能排产。
- **CRM 客户关系增强**：利用 Agent 分析历史客户数据，自动化生成跟进建议或执行营销任务。
- **IAM（身份与访问管理）自动化**：通过 Agent 辅助进行批量权限审计或自动化账号开通。
