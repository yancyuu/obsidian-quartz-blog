# 路由请求

## 定义

路由请求是该 Agent 架构中 orchestration 编排模块的核心操作，指 `router.py` 接收用户请求后根据意图将其分发到对应 Agent 或处理节点。它是连接用户入口层和具体业务 Agent 层之间的关键桥梁。路由请求与意图识别紧密关联，先识别用户意图再决定路由目标，共同实现了智能调度。该机制确保多个 Agent 可以协同工作而不互相冲突。

## 关键特征

- **意图驱动**：路由请求的前置步骤是意图识别，系统需先解析用户请求的意图，再据此决定分发目标。
- **编排核心**：作为 orchestration 编排模块的核心操作，承担统一入口的调度职责，是多 Agent 协同的中枢。
- **桥梁连接**：位于用户入口层与业务 Agent 层之间，实现请求从外部到内部处理节点的无缝传递。
- **冲突避免**：通过集中式路由分发，确保多个 Agent 协同工作时的有序调度，避免处理冲突。
- **可扩展性**：支持动态添加新的 Agent 或处理节点，路由逻辑可随业务增长灵活扩展。

## 应用

- **多 Agent 系统**：在包含多个业务 Agent 的应用中，作为统一请求分发入口，将不同意图的用户请求精准路由到对应的 Agent。
- **智能客服系统**：根据用户咨询类型（如售后、技术支持、产品咨询等），将请求路由到专业领域 Agent 进行处理。
- **复杂工作流编排**：在企业级 Agent 应用中，协调多个专业 Agent 的调用顺序与依赖关系，实现端到端的业务闭环。
