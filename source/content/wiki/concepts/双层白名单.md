# 双层白名单

## 定义
双层白名单是一种用于解决 Agent 价值观失控和触碰信仰红线问题的核心防护方法。其核心思想是将风险管理前置到 LLM 决策之前，通过两层白名单机制——信仰/敏感策略白名单与意图→工具白名单——为 Agent 划定明确的安全边界，确保 Agent 始终在禁区外活动。

## 关键特征
- **风险前置**：在 LLM 做出决策之前就完成风险拦截，而非事后补救。
- **第一层——信仰/敏感策略白名单**：明确哪些话题不能碰，为 Agent 提供一张清晰的"禁区地图"。
- **第二层——意图→工具白名单**：明确什么权限不能使用，将用户意图与可用工具进行严格映射约束。
- **三段式兜底策略**：配合"拒答/澄清/转人工"的分级处理机制，确保在边界场景下仍能安全响应。
- **以地图替代说教**：文章强调 Agent 本质上是"外行"，仅靠 Prompt 要求它专业是不够的，必须给它一张明确的禁区地图。

## 应用
- **信仰咨询类 Agent**：在宗教、信仰等高敏感领域中，防止 Agent 输出违反信仰原则的内容。
- **企业客服 Agent**：在用户意图超出 Agent 权限范围时，自动触发转人工流程。
- **内容审核与合规**：为生成式 AI 应用建立话题与权限的双重安全护栏。
