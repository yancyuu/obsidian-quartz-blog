# 结构化检索

## 定义
结构化检索是针对知识库污染问题提出的 RAG（检索增强生成）改进方案。其核心在于采用结构化索引——按章节、定义、例外等维度对文档进行细粒度组织——并配合混合召回策略，从而显著提高证据检索的精准度与完整性。相比传统简单 RAG 的单向检索（"拿到什么信什么"），结构化检索通过细粒度的文档结构划分和多种召回方式的组合，确保 Agent 获取的信息更加完整、准确，有效防止在信息不全的情况下编造答案。

## 关键特征
- **结构化索引**：按章节、定义、例外等语义维度对文档进行细粒度切分，而非简单的固定长度分块（Chunk），避免粒度不当导致的关键信息丢失。
- **混合召回策略**：组合多种检索方式（如向量检索、关键词检索等），从不同维度匹配证据，提升召回的覆盖率和精准度。
- **抗污染能力**：通过精细化结构划分和多路召回校验，降低知识库中噪声或无关信息对 Agent 决策的干扰。
- **与反思机制协同**：与数据分层隔离、反思型 RAG 共同构成知识管理的完整修复体系，形成从数据治理到检索优化再到结果验证的闭环。

## 应用
- **复杂合同与政策解析**：在解析复杂合同或政策文档时，通过按章节/条款结构化索引，确保 Agent 能完整检索到定义、例外条款等关键信息，避免因部分命中而"自信地胡说"。
- **企业问答 Agent**：为企业内部知识库提供精准的问答能力，确保员工获取的流程、制度等信息准确无误。
- **合规性审查**：在需要严格依据条款进行判断的场景中，通过混合召回确保所有相关条款均被纳入考量。
