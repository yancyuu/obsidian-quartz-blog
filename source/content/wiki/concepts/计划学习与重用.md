# 计划学习与重用

## 定义
计划学习与重用是 Magentic-UI 中实现 Agent 持续改进的核心机制。该机制允许系统保存和复用之前成功的任务执行计划，使用户可以告诉 AI 保存哪些经验，在下次遇到类似任务时 Agent 能更好地支持用户。它体现了"人教 AI"的设计理念，即用户的每一次反馈都让 Agent 更聪明、更贴合实际需求。

## 关键特征
- **经验驱动**：基于用户反馈和成功任务的执行经验进行学习，而非依赖预训练知识
- **用户主导**：用户主动决定哪些经验值得保存，赋予人类对 Agent 学习方向的控制权
- **计划复用**：将成功的任务执行计划存储并应用于类似的未来任务，提升执行效率和准确性
- **持续进化**：通过不断积累经验，Agent 能力随使用次数增加而逐步提升
- **场景适配**：保存的经验能根据实际用户需求进行调整，使 Agent 更贴合具体使用场景

## 应用
- **重复性任务加速**：当用户频繁执行类似任务时（如数据处理流程、报告生成），Agent 可复用已有计划快速完成
- **个性化工作流**：根据用户保存的历史经验，为不同用户定制差异化的任务执行策略
- **团队知识沉淀**：将团队中成功的问题解决经验保存为可复用计划，实现知识的积累与传承
- **降低用户指导成本**：Agent 经过学习后，在类似任务中减少对用户干预的需求，提升自主执行能力
