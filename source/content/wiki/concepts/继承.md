# 继承

## 定义
在该 Agent 架构中，继承指的是具体业务 Agent（如 coding_agent、research_agent）通过继承 core-agent 模块中 `base_agent.py` 定义的 Agent 基类来复用通用功能。继承机制使得所有 Agent 共享统一的生命周期管理和工具挂载接口，同时允许各子类覆盖和扩展特定行为。继承与「使用」和「挂载」共同构成了 Agent 组件间的三种基本交互模式。

## 关键特征
- **基类复用**：所有具体业务 Agent 继承自统一的基类，避免重复实现通用逻辑（如生命周期管理、工具挂载）。
- **统一接口契约**：通过继承强制所有子 Agent 遵循相同的接口规范，保证架构一致性。
- **行为扩展与覆盖**：子类可在基类基础上覆盖特定方法或扩展新行为，实现业务差异化。
- **核心组织范式**：在该架构图中多处标注「继承」关系，是 Agent 组织结构的根本范式之一。
- **三种交互模式之一**：与「使用」和「挂载」并列，构成 Agent 组件间的基本交互模式。

## 应用
- 新增业务 Agent 时，直接继承基类即可获得生命周期管理、工具挂载等通用能力，无需从零搭建。
- 在 coding_agent、research_agent 等不同业务场景中，通过覆盖基类方法实现各自专属的推理与执行逻辑。
- 架构演进时，只需修改基类即可将新能力向下传递至所有子 Agent，降低维护成本。
