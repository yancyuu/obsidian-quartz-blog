# 灰度与回滚

## 定义
灰度与回滚是 Agent 落地框架的最后阶段，核心目标是保证上线稳定性。通过小范围试用方式（如特定门店或人群）逐步发布新版本，并设定指标破线后自动退回旧版本的机制，避免新版本直接全量上线带来的风险。该方法与 SLA 定义中的成功率阈值相呼应，形成从定义目标到验证目标的闭环，是 Agent 从 Demo 走向生产力的安全保障。

## 关键特征
- **小范围试用**：先将新版本发布到特定门店或特定人群，控制影响范围
- **指标监控**：实时监控关键指标（如成功率、响应时间），与 SLA 阈值对齐
- **自动回滚**：当指标突破预设阈值时，系统自动退回旧版本，无需人工干预
- **闭环验证**：与 SLA 定义形成从目标设定到结果验证的完整闭环
- **渐进式发布**：逐步扩大灰度范围，确保每个阶段的稳定性

## 应用
- **Agent 生产上线**：新版本 Agent 上线时，先在小范围用户群中试用，验证通过后再逐步全量发布
- **门店级灰度**：在连锁零售场景中，选取部分门店先行试用新 Agent 版本，观察效果
- **风险控制**：当新版本导致成功率下降或关键指标破线时，系统自动回退到上一个稳定版本，最大限度降低业务影响
- **持续迭代**：配合 Agent 观测体系，为 Agent 的持续迭代提供安全网
