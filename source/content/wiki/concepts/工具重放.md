# 工具重放

## 定义
工具重放是一种工程方法论，指在 Agent 系统中对所有工具调用实现可重放机制——将请求和回包脱敏后完整落盘存储。该机制使开发者能够在 Bug 出现后精确回溯 Agent 的工具调用历史，在安全环境下重放整个执行过程以定位问题根因。作者将其列为上线前必做的关键工程能力之一。

## 关键特征
- **完整落盘**：所有工具调用的请求和响应数据均需持久化存储，不可遗漏
- **脱敏处理**：在落盘前对敏感数据进行脱敏，确保存储与回放过程的安全性
- **精确回溯**：支持在 Bug 发生后按时间线还原工具调用链路，逐帧定位问题
- **安全重放**：允许在隔离的安全环境中重新执行历史调用，复现故障场景而不影响生产
- **协同配合**：与四类埋点和补偿链配合使用，共同构成 Agent 可观测性和事务安全的工程基础

## 应用
- **上线前检查**：作为 Agent 系统上线检查清单中的必做项，确保所有工具调用具备可重放能力后方可发布
- **Bug 定位与调试**：当 Agent 出现异常行为时，通过重放历史工具调用精确定位根因
- **事故演练支撑**：在随机注入工具失败的事故演练中，通过重放机制验证补偿闭环的有效性
- **审计与合规**：为 Agent 的工具调用行为提供完整的可追溯记录，满足审计需求
