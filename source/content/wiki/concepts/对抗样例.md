# 对抗样例

## 定义
对抗样例是 Agent 上线前"低成本正确性"清单中要求准备的测试用例，针对每个关键意图配备 10 条包含方言、口误、歧义和脏话的对抗性输入。这些样例用于在上线前模拟真实世界中用户可能给 Agent 带来的干扰和边界测试，确保 Agent 在非理想输入下仍然能正确识别意图并安全响应。对抗样例配合工具重放、事故演练等手段一起使用，构成 Agent 上线前的质量保障闭环。

## 关键特征
- **数量固定**：每个关键意图配备 10 条对抗样例，形成标准化的测试覆盖。
- **覆盖多维干扰**：包含方言、口误、歧义和脏话四大类非理想输入场景，模拟真实用户行为。
- **意图导向**：以关键意图为粒度组织对抗样例，确保核心业务路径的鲁棒性。
- **与安全闭环协同**：配合工具重放、事故演练等手段一起使用，构成上线前质量保障闭环。
- **低成本高效益**：以较低投入预先暴露 Agent 在极端场景下的缺陷，避免线上事故。

## 应用
- **Agent 上线前测试**：在 Agent 发布前用对抗集（对抗样例集合）对全量关键意图跑一遍，验证意图识别的准确性与安全性。
- **质量保障闭环**：与工具重放、事故演练等手段配合，形成"测试—修复—复测"的完整质量保障流程。
- **边界场景验证**：针对脏话、歧义等可能导致 Agent 异常行为的边界输入进行专项检测，防止出现不当响应。
