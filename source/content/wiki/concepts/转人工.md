# 转人工

## 定义
转人工是一种安全兜底策略，指当 Agent 在执行过程中遇到异常分支、校验失败或无法自主处理的场景时，将对话流程确定性转接至人工客服。在基于有限状态机（FSM）的 Agent 架构设计中，转人工体现为一种基于规则的硬约束——例如身份校验（VERIFY_IDENTITY）失败时，系统不依赖 LLM 自行判断和处理，而是直接跳转到 ESCALATE_TO_HUMAN 状态，从而避免因模型幻觉导致的越权操作。

## 关键特征
- **确定性跳转**：基于预定义规则触发，而非依赖 LLM 的概率性判断，确保关键路径上的行为可预测
- **安全兜底**：作为系统安全的最后一道防线，防止 Agent 在异常情况下做出不可控行为
- **硬约束机制**：通过状态机中的固定转移规则实现，禁止 LLM 在敏感节点自行决策
- **人机协同边界**：明确了 Agent 自动化能力的边界，将无法可靠处理的场景交由人工介入

## 应用
- **身份校验失败**：用户身份无法确认时，直接转人工处理，避免未经授权的敏感操作
- **异常分支处理**：Agent 遇到未覆盖的业务场景或意外输入时，安全退出至人工通道
- **高风险业务节点**：在涉及资金、权限变更等关键环节，设置转人工作为默认兜底
- **合规要求场景**：满足金融、医疗等行业的监管要求，确保关键决策有人工参与
