# 类型提示

## 定义
类型提示（Type Hints）是 Python 编程中的一种标准规范，要求在函数签名中显式标注参数和返回值的数据类型。在 AI Agent 工程实践中，类型提示被提升为强制约束，确保所有函数签名都使用类型声明，优先采用 Pydantic 模型替代原始字典进行输入验证，并在 Sanic 路由定义中附带明确的返回类型注释。它不仅是代码质量的保障手段，更是让 AI Agent 正确理解和生成结构化代码的基础约束。

## 关键特征
- **强制函数签名标注**：所有函数必须对参数和返回值进行类型提示，不允许省略
- **优先使用 Pydantic 模型**：进行输入验证时，优先使用 Pydantic 模型而非原始字典（`dict`），以获得更强的运行时校验能力
- **声明式路由返回类型注释**：在 Sanic 等框架的路由定义中，必须携带明确的返回类型注释
- **AI Agent 结构化理解基础**：类型提示为 AI Agent 提供了代码接口的精确语义信息，是 Agent 正确理解、生成和维护结构化代码的前提条件
- **静态可分析性**：通过类型标注，可借助 mypy 等工具在编译期进行静态类型检查，提前发现潜在错误

## 应用
- **AI Agent 代码生成**：为 AI Agent 提供精确的接口契约，确保生成的代码符合类型规范
- **Web 框架路由定义**：在 Sanic、FastAPI 等框架中，通过返回类型注释实现自动文档生成和接口校验
- **输入数据验证**：结合 Pydantic 模型，在 API 请求入口处对数据进行严格的运行时校验
- **大型项目维护**：在团队协作中，类型提示作为自文档化机制，降低沟通成本和维护风险
