# 挂载

## 定义

在 agent_app 的架构中，挂载是一种将通用功能模块动态绑定到具体 Agent 的机制。与「继承」和「使用」并列，挂载是三种模块复用方式之一，允许 Agent 在运行时按需引入 modules 中的工具和功能，而非在编译期静态绑定。这种设计使得 Agent 的能力可以灵活扩展，同时保持核心逻辑的简洁。挂载机制通常应用于 tools-actions 模块和 memory-context 模块中，为 Agent 提供工具调用和记忆检索能力。

## 关键特征

- **动态绑定**：Agent 在运行时按需引入 modules 中的功能模块，而非编译期静态绑定，实现灵活的能力扩展。
- **解耦复用**：作为三种模块复用方式之一（与「继承」和「使用」并列），挂载实现了 Agent 核心逻辑与通用功能模块之间的解耦。
- **场景化应用**：主要应用于 tools-actions 模块（工具调用能力）和 memory-context 模块（记忆检索能力），为不同 Agent 提供差异化的能力组合。
- **核心逻辑保持简洁**：Agent 无需在自身代码中包含所有功能实现，通过挂载机制即可获得丰富的工具与记忆能力。

## 应用

- **工具能力扩展**：为特定 Agent 挂载 tools-actions 模块中的工具集，使其具备搜索、数据分析、API 调用等能力。
- **记忆与上下文注入**：通过挂载 memory-context 模块，让 Agent 在运行时获得历史对话记忆、长期记忆及上下文检索能力。
- **按需能力组合**：不同业务场景下的 Agent 可以挂载不同的模块组合，实现能力的按需装配，避免功能冗余。
- **模块独立维护**：功能模块独立开发与维护，通过挂载机制按需注入到各个 Agent 中，提升开发效率和代码复用率。
