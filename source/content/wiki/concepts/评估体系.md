# 评估体系

## 定义
评估体系（Evals）是一种用于衡量 AI Agent 智能水平的自动化测试框架。与针对确定性系统的传统单元测试不同，评估体系专门应对 Agent 这类概率性系统的非确定性输出，通过系统化、量化的方式替代主观的"凭感觉"判断，从而精确衡量 Agent 的实际表现。

## 关键特征
- **自动化测试**：通过自动化流程持续衡量 Agent 的智能水平和任务完成质量。
- **针对非确定性输出**：区别于传统软件的确定性测试，专门适应大模型概率性输出的特征。
- **量化衡量**：将 Agent 的表现转化为可量化的指标，避免主观偏见。
- **首要工程任务**：被视为企业和开发者掌握 Agent 管控能力（即"驯兽"技巧）的核心基础工作。

## 应用
- **企业 Agent 开发**：在构建企业级 Agent 时，建立评估体系作为质量保障的核心环节。
- **模型迭代验证**：在更换底层大模型或调整 Agent 架构时，通过 Evals 量化验证性能变化。
- **持续集成（CI）**：将 Agent 评估集成到开发流水线中，确保每次代码或提示词变更不会导致智能水平退化。
