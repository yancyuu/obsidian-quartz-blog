## 1. 项目概述

### 1.1 项目背景

SKG 内部需要一个专业的采购物料查询助手，帮助员工快速查询物料采购成本信息，包括物料名称、供应商、采购单价、MOQ、报价日期等关键数据。

### 1.2 核心功能

- 基于自然语言的物料查询
- 产品信息检索与成本分析
- 多轮对话上下文管理
- 飞书机器人集成

## 2. 技术架构

### 2.1 技术栈

| 层级 | 技术选型 | 说明 |
|-|-|-|

### 3.2 工具函数

#### 3.2.1 list_products - 产品列表查询

```Python
async def list_products(
    ctx: RunContext[BOMAgentState],
    alias: Optional[List[str]] = None,  # 型号精确匹配
    query: Optional[str] = None         # 语义搜索
) -> dict
```

**召回策略**：

- 双路召回：alias 精确匹配 + query 语义搜索
- OR 融合：按 product_id 去重，alias 结果优先
- query 路：相似度 > 0.8，最多 10 条

#### 3.2.2 search_procure_materials_by_product_id - 采购物料详情

```Python
async def search_procure_materials_by_product_id(
    ctx: RunContext[BOMAgentState],
    product_id: str  # 产品ID (纯数字)
) -> dict
```

**返回字段**：

- 物料编码、物料名称、规格型号
- 供应商名称、是否主力供应商
- 采购单价、货币、价格单位
- MOQ、报价日期、有效期
- 采购人、采购组、采购周期

#### 3.2.3 get_procure_materials_by_desc - 物料描述查询 (兜底)

```Python
async def get_procure_materials_by_desc(
    ctx: RunContext[BOMAgentState],
    item_desc: str  # 物料描述
) -> dict
```

## 4. Prompt 设计

### 4.1 产品查询 Prompt (product_inquiry.md)

**核心红线**：

1. 纯文本输出，禁止 Markdown 语法
2. 禁止通用品类词，必须使用具体型号
3. 真人聊天口吻，禁止机器客服套话
4. 隐匿数据来源，用第一人称自然表达
5. 不输出敏感信息 (产品别名、product_id)

**查询流程**：

1. 快捷通道：用户消息包含纯数字 product_id → 直接调用详情接口
2. 常规查询：list_products → 获取 product_id → search_procure_materials_by_product_id
3. 兜底方案：查询为空 → get_procure_materials_by_desc

### 4.2 意图识别 Prompt (bom_intent.md)

**意图类型**：

- `greeting` - 打招呼
- `reset_session` - 重置会话
- `query_material` - 查询物料
- `chitchat` - 闲聊

async def reply_to_user(data: P2ImMessageReceiveV1):

## 8. 扩展性设计

### 8.1 多 Agent 支持

通过 `AgentSessionCache` 泛型设计，支持不同 Agent 的会话管理：

```Python
cache = await get_agent_session_cache("bom_cost")
cache = await get_agent_session_cache("other_agent")
```

### 8.2 工具扩展

在 `config.py` 中注册新工具：

```Python
def _create_tools_with_retries():
    return [
        Tool(list_products, max_retries=3),
        Tool(new_tool, max_retries=3),
    ]
```
