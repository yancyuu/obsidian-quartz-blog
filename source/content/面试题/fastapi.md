### **1. FastAPI 依赖注入与部署**

**问题 1**:  
**FastAPI** 的依赖注入是如何工作的？请举一个实例，说明你如何在 **FastAPI** 中实现 **依赖注入**，并解释它如何帮助简化代码的可维护性和可扩展性。

**考察点**：

- **FastAPI的依赖注入机制**：理解 FastAPI 中的 **依赖注入**，如何使用 **Depends** 来解耦业务逻辑。
- **代码结构**：如何将 **依赖注入** 与 **路由处理** 和 **数据库交互** 分离。
    

**参考答案**：

- **FastAPI依赖注入** 通过 `Depends` 类实现，可以将重复的业务逻辑或服务层抽象出来，提高代码的可重用性和可维护性。通常会将数据库连接、配置文件或缓存等组件作为依赖注入到视图函数中。
    
    `from fastapi import FastAPI, Depends from sqlalchemy.orm import Session from .database import get_db  app = FastAPI()  def get_user(db: Session, user_id: int):     return db.query(User).filter(User.id == user_id).first()  @app.get("/users/{user_id}") def read_user(user_id: int, db: Session = Depends(get_db)):     return get_user(db, user_id)`
