## 🎯 高级面试题（Agent 开发方向）

### **模块 A：Agent 架构与设计**

1. 你怎么理解 “Agent” 在你们业务里具体是什么？与传统服务／微服务的区别在哪里？
    
2. 描述你搭建过的一个多 agent 系统（或 react 模式）— 包括：调度器、评估器、执行器、工具调用、RAG／检索模块。
    
3. 在你们系统中，如何划分 “工具” vs “MCP/Agent” 的边界？举一个具体的流程说明。
    
4. 多 agent 系统中，分析 “规划（Planner）”、“执行（Executor）”、“评估（Evaluator）” 这三类角色，举例你自己系统里谁做的是什么。参考：规划 agent 、执行 agent 、优化 agent 。 [Skphd+1](https://skphd.medium.com/design-patterns-in-agentic-ai-interview-questions-and-answers-6e77e4ca72e2?utm_source=chatgpt.com)
    
5. 如果你要支持 “新赛道／新业务场景” 而你当前系统不能直接支持，架构上你会做哪些设计调整以支持快速扩展？
    

### **模块 B：RAG／检索增强生成流程**

6. 在你说的业务中，RAG（Retrieval‑Augmented Generation）流程是怎么落地的？包括：文本分块、向量化、召回、过滤／评估、合成。
    
7. 如果你发现 RAG 返回结果“不准”或“偏离业务需求”，你会从哪些维度优化？（例如：文本分块、索引策略、嵌入维度、检索算法、评估机制）—你刚才提了一些。
    
8. 你有没有用 Self‑RAG 或 循环检索 + 评估的架构？如果没有，你会如何设计这种结构？
    
9. 向量数据库召回后，如何保证检索出来的信息“及时”“业务相关”“去噪”？你有没有做过质量控制机制？
    
10. 在你们系统里，检索链和生成链的延迟／性能瓶颈通常在哪？你是怎么监控／优化的？
    

### **模块 C：Agent 与工具调用／上下文工程**

11. 描述你们系统中从“用户输入”到“工具调用”再“工具输出”再“Agent反馈给用户”的完整流程。在哪些节点你加入日志／监控？
    
12. 当大模型错误调用了工具（你刚提到可能会发生）你是如何检测和纠错的？你有没有自动化监控、报警或者模型自动反馈机制？
    
13. 上下文工程（多轮对话）和单轮对话差别在哪？在多轮场景下你们是如何处理上下文压缩／摘要／提取的重要信息的？
    
14. 你如何决定“这一步用大模型” vs “这一步用小模型” vs “这一步本地逻辑” — 你们的策略是什么？举出你自己的判断标准。
    
15. 在你们 agent 系统里，是否存在“记忆（Memory）”模块？包括短期对话记忆、用户偏好记忆、业务状态记忆。你是怎么设计的？参考 memory 在 agent 中的作用。 [Skphd+1](https://skphd.medium.com/top-20-ai-agents-interview-questions-and-answers-aebad2c73094?utm_source=chatgpt.com)
    

### **模块 D：部署、监控、评估与优化**

16. 你们系统中如何设计 “链路追踪／日志／监控面板” 来定位哪个模块出问题？描述你用过的工具或自己实现的。
    
17. 当 agent 回答不符合业务或用户习惯（你刚讲到80%大模型+20%人工）时，你们是怎么反馈到系统里的？是人工标注→微调？还是自动标注？过程如何？
    
18. 在 agent 系统上线后，你们如何做 A/B 测试或 实验 评估？你关注哪些 KPI？例如：准确率、召回率、用户满意度、工具调用成功率。
    
19. 从系统性能、成本、扩展性角度看，当你将 大模型微调部署本地／量化时，你会优先考虑哪些因素？
    
20. 安全、风险、治理方面：当 agent 可以调用外部工具／联网查网页／有自动决策能力时，你怎么防止 “误操作”／“工具滥用”／“模型偏差”？
    

### **模块 E：业务贴合与产品意识**

21. 在你提的“精准匹配用户兴趣→推视频／广告”这个业务中，你认为 agent 系统哪些环节最关键？（例如：兴趣建模、检索候选、投放排序、反馈闭环）
    
22. 如果用户画像／兴趣标签不够精细，导致推荐不精准，你会怎么从系统角度改进？
    
23. 你刚讲的大模型用来“预测新赛道”的能力，从产品化角度看，会有哪些挑战？你如何设计流程把模型能力转化成线上可用功能？
    
24. 当业务发生变化（比如新视频赛道、新广告类型）系统如何快速适配？你们架构支持这种快速适配吗？具体流程怎样？
    
25. 与非技术团队（产品、运营、数据）对接时，当他们说“我们想一个能自动生成视频推荐理由的 agent”你会如何用工程语言向他们解释能力边界与技术可行性？
